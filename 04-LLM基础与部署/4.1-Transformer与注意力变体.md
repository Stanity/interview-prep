## 1. 30 秒口述版

:::card 30 秒版
「Transformer 的核心是 **self-attention**：每个 token 用自己的 **Query** 去和所有 token 的 **Key** 算相似度，得到权重后对 **Value** 加权求和。写成公式就是 `softmax(QK^T/√d_k)·V`。

它比 RNN 好在两点：**可以并行**（不用逐步传递隐状态）、**任意两个位置的距离都是 1**（长程依赖不用过中间节点）。

但代价是 **O(n²)** 的复杂度 —— 序列长度翻倍，注意力的计算和显存都翻 4 倍，这是长上下文的根本瓶颈，也直接催生了后面三条优化线：**变体（MQA/GQA/MLA 省 KV cache）、算法（FlashAttention 省显存带宽）、系统（PagedAttention/连续批处理提吞吐）**。」
:::

最后一句很关键：它把 4.1 和 4.4 串起来了。

## 2. Self-Attention 的完整计算（必须能白板写）

### 2.1 Q/K/V 从哪来

:::card 三句话
输入是 `n` 个 token 的表示矩阵 `X in R^{n×d_model}`，用三个**可学习**的投影矩阵得到：
```
Q = X W_Q ,  K = X W_K ,  V = X W_V
```
- **Query（查询）**：我想找什么
- **Key（键）**：我能提供什么（用于被匹配）
- **Value（值）**：我实际携带的内容（被加权取走）

**为什么要把 Q/K 和 V 分开**：匹配用的"身份"和取走用的"内容"**解耦** —— 同一个 token 在不同上下文里可以被匹配到（key 相同）但贡献不同的内容（value 可学）。
:::

### 2.2 公式与形状

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\Big(\frac{QK^{\top}}{\sqrt{d_k}}\Big)V
$$

| 张量 | 形状 |
|---|---|
| `Q` | `n × d_k` |
| `K` | `n × d_k` |
| `V` | `n × d_v` |
| `QK^T` | `n × n`（**注意力矩阵**） |
| 输出 | `n × d_v` |

### 2.3 为什么除以 √d_k（必背）

:::card 推导 + 直觉
**推导**：假设 `q` 和 `k` 的各分量独立、均值 0、方差 1，则点积
$$
q\cdot k=\sum_{i=1}^{d_k}q_i k_i
$$
的方差是 `d_k`（各分量方差相加）。所以 `std(q·k) = √d_k`。

**不缩放会怎样**：`d_k = 128` 时点积的标准差约 11，数值范围被放大 → softmax 输入过大 → **进入饱和区**，输出接近 one-hot，**梯度接近 0**（softmax 在饱和区导数极小）。

**除以 √d_k** 把方差归一到 1，softmax 落在"有区分度但不饱和"的区间。

**一句话**：「除以 `√d_k` 是为了**把点积的方差归一化**，防止 softmax 饱和导致梯度消失。」
:::

### 2.4 复杂度（必须能推）

:::card 时间与空间
| 步骤 | 计算量 |
|---|---|
| `QK^T` | `n×d_k` 乘 `d_k×n` → **O(n² d)** |
| `softmax` | `O(n²)` |
| `·V` | `n×n` 乘 `n×d_v` → **O(n² d)** |
| **合计** | **O(n² d)** |

**空间**：注意力矩阵 `n × n` → **O(n²)**（这就是长序列显存爆炸的根源）

**对比其他层**：
- FFN：`O(n · d²)`（与序列长度**线性**）
- 所以序列短时 FFN 主导，**序列长（n > d）时注意力主导**

**面试话术**：「注意力的复杂度是 `O(n²d)`，FFN 是 `O(nd²)`。所以长上下文场景下注意力是瓶颈，长上下文优化的核心就是**别把 n×n 矩阵完整落到显存里**（FlashAttention）或者**缩小 K/V 的表示**（GQA/MLA）。」
:::

## 3. 为什么 Self-Attention 优于 RNN

:::card 三点，每条都要说清"代价"
| 维度 | RNN/LSTM | Self-Attention |
|---|---|---|
| **并行性** | ❌ 必须逐步递推（t 依赖 t-1） | ✅ 所有位置同时算 |
| **长程依赖** | 路径长度 O(n)（信息要逐步传） | **路径长度 O(1)**（任意两位置直接相连） |
| **归纳偏置** | 有顺序先验 | 无顺序先验 → **必须显式加位置编码** |

**注意最后一行**：attention 对输入是**置换不变**的（打乱顺序结果一样），所以位置信息必须**显式注入** —— 这就是位置编码（RoPE）存在的理由，详见 4.2。

**代价**：`O(n²)` 的复杂度 + 显存，以及推理时需要 KV cache。
:::

## 4. 多头注意力（MHA）为什么有效

:::card 两个层次
**① 子空间多样性**
每个头有自己的 `W_Q/W_K/W_V`，把输入投到**不同的子空间**，学不同的关系（有的头关注语法依赖、有的关注指代、有的关注局部 n-gram）。单头只能学一种"加权方案"。

**② 稳定与表达力的平衡**
把 `d_model` 切成 `h` 个头（每头 `d_k = d_model / h`），**总计算量与单头相同**（因为维度被切分了），但表达力更强。

**常见的头数与头维**：
| 模型 | d_model | 头数 h | d_head |
|---|---|---|---|
| Llama-3.1-8B | 4096 | 32 | 128 |
| 一般规律 | — | — | **128 是常见选择** |
:::

**面试追问准备**：「多头是不是等于"把大矩阵拆开算"？」→ **不是**，因为每个头有独立的 Q/K/V 投影，多个头的结果 concat 后再过一个 `W_O`，这**等价于在更低秩的子空间里做多次不同的注意力**，表达力严格强于单头（单头是 h=1 的特例）。

## 5. Pre-LN vs Post-LN

:::card 两种排布
**Post-LN（原始 Transformer）**
```
x = LayerNorm(x + Attention(x))
x = LayerNorm(x + FFN(x))
```
- 归一化在**残差相加之后**
- 训练**不稳定**，需要**学习率 warmup**，层数深了容易梯度爆炸

**Pre-LN（现在的主流）**
```
x = x + Attention(LayerNorm(x))
x = x + FFN(LayerNorm(x))
```
- 归一化在**子层之前**，残差路径是**恒等路径（identity path）**
- 好处：**梯度可以沿残差直通**，训练稳定，对 warmup 不敏感
- 代价：需要**在最后加一个 final norm**（否则输出尺度会随层数累积）

**一句话**：「Pre-LN 把残差路径保持干净，梯度能直接回传，所以能训得更深更稳；代价是要补一个 final LayerNorm。」
:::

## 6. RMSNorm vs LayerNorm

:::card 公式对比（能写出来就够）
**LayerNorm**：
```
y = (x − μ) / √(σ² + ε) · γ + β        （减均值、除标准差、缩放+平移）
```
**RMSNorm**：
```
y = x / √( mean(x²) + ε ) · γ          （不减均值、只用均方根、只有缩放）
```

**三个差别**：
1. **不减均值** → 少一次统计量与减法
2. **没有 β（平移）** → 参数更少
3. **更快**（实测约快 5%–10%），**效果相当**（在 LLM 上被广泛验证）

**为什么可以不减均值**：LLM 的隐状态本身均值接近 0（尤其过了残差之后），减不减影响不大；而"除以幅度"才是关键的归一化。

**面试话术**：「RMSNorm 是 LayerNorm 的简化版，去掉中心化和平移，速度略快、效果不掉，所以 Llama 系列都用它。」
:::

## 7. FFN 的作用

:::card FFN 到底在干什么
```
FFN(x) = W_2 · Act(W_1 x)          （先升维到 4d，再降回 d）
```
**两个视角**：
1. **逐位置的非线性变换**：attention 只做"加权求和"（线性），FFN 提供**非线性**
2. **知识的存储位置**：FFN 参数量约占模型 2/3，被广泛认为承载了"事实知识"（key-value memory 视角）
   → 这也是 LoRA 要把 FFN 加进 `target_modules` 的原因（见 3.5）

**SwiGLU（现代主流）**：
$$
\begin{aligned}\operatorname{FFN}(x)&=W_2\big(\operatorname{SwiGLU}(W_g x,\,W_u x)\big)\\[-2pt]\operatorname{SwiGLU}(a,b)&=a\odot\operatorname{SiLU}(b)\end{aligned}
$$
- 引入**门控**（一个分支当"门"），比 ReLU/GELU 效果好
- 代价：多一个投影矩阵 → 为了保持参数量不变，**hidden 维度从 4d 降到约 8d/3（即 2/3 × 4d）**
:::

## 8. Decoder-only 为什么成为主流

:::card 四个理由
1. **训练目标统一**：就是 next-token prediction，一个目标适配所有任务（无需任务头）
2. **zero-shot / in-context 能力强**：同一套参数通过 prompt 就能切换任务
3. **推理友好**：因果掩码 + **KV cache** 天然适配自回归生成（Encoder-Decoder 的 cross-attention 还要额外缓存编码端）
4. **scaling 简单**：结构单一，加宽加深就是更大的模型，工程上最省事

**对比**：
| 架构 | 擅长 | 为什么没成为 LLM 主流 |
|---|---|---|
| Encoder-only（BERT） | 理解类任务（分类、抽取） | 不能生成 |
| Encoder-Decoder（T5） | 翻译、摘要 | 结构复杂、生成时多一份 cross-attention 开销 |
| **Decoder-only** | 通用生成 | —— |
:::

## 9. 四个注意力变体（**重点，必背对比表**）

先给结论表，再逐个解释：

| 变体 | K/V 的头数 | KV cache 相对 MHA | 表达力 | 代表模型 |
|---|---|---|---|---|
| **MHA** | = Q 的头数 `h` | 1×（基准） | 最强 | GPT-3、Llama-1 |
| **MQA** | **1**（所有 Q 头共享） | **1/h** | 略降 | PaLM、Falcon |
| **GQA** | `g` 组（`1 < g < h`） | **g/h** | 接近 MHA | **Llama-2/3、Qwen2/3、Mistral** |
| **MLA** | 低秩 latent（不上缓存完整 K/V） | **远小于 1**（约 1/10 量级） | 强 | **DeepSeek-V2/V3** |

### 9.1 MQA（Multi-Query Attention）

:::card 做法与代价
**做法**：Q 有 `h` 个头（各不同），但 **K/V 只有 1 个头**，所有 Q 头共享同一份 K/V。

**收益**：KV cache **直接降到 1/h**。以 `h=32` 为例，KV cache 缩小 32 倍 —— 这在长上下文/大 batch 场景是巨大收益。

**代价**：表达力下降（所有头被迫用同一套"键值表示"），训练时可能不稳定，效果有小幅损失。
:::

### 9.2 GQA（Grouped-Query Attention）——**当代主流**

:::card 做法
把 `h` 个 Q 头分成 `g` 组，**每组共享一份 K/V**。
- `g = h` → 退化成 MHA
- `g = 1` → 退化成 MQA
- 中间值 → 折中

**Llama-3.1-8B 的实际配置**：`h = 32` 个 Q 头，**`g = 8` 个 KV 头** → KV cache 是 MHA 的 **1/4**。

**为什么成为主流**：几乎保留 MHA 的效果，同时把 KV cache 砍到 1/4 —— 对推理成本的影响是直接的。
:::

### 9.3 MLA（Multi-head Latent Attention）——DeepSeek 的路线

:::card 做法（一句话 + 关键点）
**做法**：不缓存完整的 K/V，而是把 K/V **压缩成一个低维 latent 向量** 缓存起来，用的时候再投影回 K/V 空间。

**关键点**：因为 K/V 是由同一个输入经过线性变换得到的，它们本身**存在低秩冗余**；DeepSeek 用低秩分解把这个冗余压掉。

**收益**：
- KV cache 比 MHA 小一个数量级（实测约 1/10 量级）
- 而且**效果不掉**（甚至更好），因为它保留了 MHA 的表达力（不是靠减少头数换空间）

**代价**：实现复杂（要处理 RoPE 与压缩的交互），训练时需要额外设计。

**面试话术**：「MQA/GQA 是**减少 KV 的头数**来省显存，代价是表达力；MLA 是**压缩 KV 的表示**来省显存，靠低秩分解，理论上更"划算"——这也是 DeepSeek 能把长上下文做便宜的原因之一。」
:::

### 9.4 KV cache 大小的公式（**五星高频，必须会算**）

:::card 公式
```
KV cache 字节数 = 2 × layers × n_kv_heads × d_head × seq_len × batch × bytes_per_elem
                    ↑
              (K 和 V 各一份)
```
:::

:::card 三个算例（手算，面试直接报）
**例 1：Llama-3.1-8B（GQA，8 KV 头），fp16，8k 上下文，batch=1**
$$
\begin{aligned}&2\times 32\ (\text{K,V})\times 8\ (\text{heads})\times 128\ (\dim)\times 8192\ (\text{seq})\times 2\ (\text{bytes})\\ =\ &1{,}073{,}741{,}824\ \text{bytes}\approx 1.0\ \text{GB}\end{aligned}
$$
→ **单条 8k 序列的 KV cache 约 1 GB**

**例 2：同上，batch = 32**
```
1.0 GB × 32 = 32 GB     ← 还没算权重（16 GB）和激活
```
→ 这就是"为什么长上下文 + 大 batch 会 OOM"

**例 3：如果换成 MHA（32 KV 头）**
```
1.0 GB × (32/8) = 4 GB / 序列
batch 32 → 128 GB   ← 直接不可行
```
→ **这就是 GQA 存在的意义**：把 KV cache 从 128 GB 降到 32 GB

**答题模板**：「公式是 `2 × 层数 × KV头数 × 头维 × 序列长 × batch × 精度字节`。以 8B/GQA-8头/8k 为例，单序列约 1 GB，batch 32 就是 32 GB —— 所以长上下文的成本主要在 KV cache，不在权重。」
:::

## 10. FlashAttention：为什么快（**不是近似**）

:::card 问题在哪
标准 attention 要显式算出 `n × n` 的注意力矩阵并**写回 HBM（显存）**，再读回来做 softmax 和乘 V。
- 序列 `n = 8192` 时，单头单层的注意力矩阵就是 `8192² × 2 bytes ≈ 128 MB`
- 而且**反复读写 HBM** —— 现代 GPU 的瓶颈是**显存带宽**，不是算力

**一句话**：「标准 attention 慢，不是因为算得多，而是因为**来回搬了太多数据**。」
:::

:::card 三个关键技术
1. **分块（tiling）**：把 Q/K/V 切成小块，让一个小块能塞进 **SRAM（片上缓存，比 HBM 快一个数量级）**，在片上算完再写回
2. **在线 softmax（online softmax）**：softmax 需要全局最大值做数值稳定，但分块后看不到全局 → 用**增量更新**的方式维护 running max 和 running sum，边算边修正
3. **重算（recompute）**：反向传播不存储中间的 `n×n` 矩阵，而是**用保存的统计量重新算一遍** —— 用算力换显存

**收益**：
- 显存从 `O(n²)` 降到 **`O(n)`**
- 速度提升（少搬数据），长序列下更明显
:::

:::card 一个必须说清的点：FlashAttention 是**精确**注意力
它**不改变数学结果** —— 算出来的仍是标准 attention（`softmax(QK^T/√d)V`），只是**换了计算顺序和存储方式**。

**这和"稀疏注意力/线性注意力"有本质区别**：后者是**近似**，会损失效果。

**面试话术**：「FlashAttention 是 IO-aware 的**精确**实现：分块 + 在线 softmax + 反向重算，把显存从 O(n²) 降到 O(n)，数学上完全等价。」
:::

## 11. 十二个追问预答

:::qa Attention 为什么除以 √d_k？不除会怎样
点积 `q·k` 的方差是 `d_k`，`d_k=128` 时标准差约 11 → softmax 输入过大 → 进入饱和区 → 输出近 one-hot → **梯度接近 0**。除以 √d_k 把方差归一化到 1。
:::

:::qa Self-Attention 的复杂度是多少？为什么长上下文难
时间 `O(n²d)`、空间 `O(n²)`。序列翻倍，注意力的计算和显存都 **4 倍**。对比 FFN 是 `O(nd²)`（线性），所以长序列时注意力主导。
:::

:::qa Q/K/V 分别是什么？为什么要把 V 和 K 分开
Q 是"我要找什么"，K 是"我能被怎么匹配"，V 是"我实际贡献的内容"。分开是为了**匹配身份与内容解耦** —— 同一个 token 可以被同一种 key 匹配到，但对不同 query 贡献不同内容。
:::

:::qa 多头注意力的"多"有什么用？计算量会变多吗
每个头有独立的 Q/K/V 投影，学**不同子空间的关系**。因为把 `d_model` 切成 `h` 份，**总计算量与单头基本相同**，但表达力更强。
:::

:::qa Pre-LN 和 Post-LN 的区别？为什么现在用 Pre-LN
Pre-LN 把归一化放在子层**之前**，残差路径是干净的恒等路径 → 梯度可直接回传、训练稳定、对 warmup 不敏感。代价是要在最后补一个 final norm。
:::

:::qa RMSNorm 和 LayerNorm 差在哪？为什么能不减均值
LN 减均值除标准差再缩放平移；RMS 只除以均方根、只有缩放。因为 LLM 隐状态均值接近 0，中心化贡献小，而"除以幅度"才是关键。速度略快、效果相当。
:::

:::qa FFN 有什么用？为什么现在都用 SwiGLU
FFN 提供**非线性**（attention 是线性的加权求和），并且承载大部分参数/知识。SwiGLU 引入**门控**，效果优于 ReLU/GELU；为保持参数量把 hidden 从 4d 降到约 8d/3。
:::

:::qa MHA / MQA / GQA 的区别
MHA：每个 Q 头有自己的 K/V；MQA：所有 Q 头共享 1 份 K/V（cache 降 1/h）；GQA：分成 g 组，每组共享一份（cache 降 g/h）。GQA 是当代主流（Llama-3 是 32 Q 头 / 8 KV 头）。
:::

:::qa MLA 和 GQA 的思路差在哪
GQA 是**减少 KV 的头数**（省空间但损表达力）；MLA 是**压缩 KV 的表示**（低秩 latent，用的时候投影回来），理论上更划算，且效果不掉。
:::

:::qa 算一下 8B 模型 8k 上下文的 KV cache
`2 × 32 层 × 8 KV头 × 128 头维 × 8192 × 2 bytes ≈ 1 GB`（batch=1）。batch 32 就是 32 GB。若换成 MHA（32 KV 头）则是 4 GB/序列。
:::

:::qa FlashAttention 为什么快？它是近似算法吗
**不是近似**，是精确注意力。快是因为**减少了 HBM 读写**：分块把数据放进 SRAM、用在线 softmax 增量维护统计量、反向重算代替存储 `n×n` 矩阵。显存从 `O(n²)` 降到 `O(n)`。
:::

:::qa Decoder-only 为什么成为主流
① 训练目标统一（next-token）② in-context/zero-shot 强 ③ KV cache 天然适配自回归 ④ 结构单一、scaling 工程简单。
:::

## 12. 陷阱

| ❌ 别这么说 | ✅ 换成这么说 |
|---|---|
| 「Attention 的复杂度是 O(n²)」 | 「时间 `O(n²d)`、空间 `O(n²)`；FFN 是 `O(nd²)`」 |
| 「MQA 省算力」 | 「MQA 省的是 **KV cache 显存**（降 1/h），不是算力」 |
| 「GQA 是 MQA 的改进版」 | 「GQA 是 MHA 与 MQA 的**折中**：分组共享 K/V」 |
| 「FlashAttention 是近似注意力」 | 「它是**精确**注意力，优化的是 IO 与显存，不改数学结果」 |
| 「RMSNorm 比 LayerNorm 效果更好」 | 「效果相当，但**更快、参数更少**」 |
| 「位置编码可有可无」 | 「attention 是**置换不变**的，位置信息必须显式注入」 |

## 13. 自测（8 题）

:::qa 写出 attention 公式，并说明每个张量的形状
`softmax(QK^T/√d_k)V`。Q: n×d_k，K: n×d_k，V: n×d_v，QK^T: n×n，输出 n×d_v。
:::

:::qa 为什么除以 √d_k？用方差说
`q·k` 的方差是 `d_k`（各分量方差相加），不缩放时 softmax 输入过大进入饱和区、梯度趋零。除以 √d_k 把方差归一到 1。
:::

:::qa attention 和 FFN 的复杂度分别是什么？谁在长序列时主导
attention `O(n²d)`，FFN `O(nd²)`。当 `n > d` 时 attention 主导。
:::

:::qa Pre-LN 的两个好处和一个代价
好处：残差路径干净、梯度直通 → 训练稳定、对 warmup 不敏感。代价：需要 final norm。
:::

:::qa MHA / MQA / GQA / MLA 各自的 KV cache 相对大小
MHA 1×；MQA 1/h；GQA g/h（Llama-3 是 1/4）；MLA 约 1/10 量级（低秩 latent）。
:::

:::qa 写出 KV cache 的公式并算 8B/GQA-8头/8k/batch1
`2×layers×n_kv_heads×d_head×seq×batch×bytes = 2×32×8×128×8192×2 ≈ 1 GB`。
:::

:::qa FlashAttention 的三个关键技术和一个"不是"
分块（tiling）、在线 softmax、反向重算。**不是**近似算法（数学等价）。
:::

:::qa 为什么 attention 必须配位置编码
Self-attention 对输入顺序是**置换不变**的（打乱输入输出只是同样打乱），本身不含位置信息，所以必须显式注入（RoPE 见 4.2）。
:::
