# 8.2 模拟面试 3 轮 + 面试当天速览卡

> **这篇的用法**：找一个朋友（或对着录音）按这三轮走一遍。**关键不是"答对"，而是"能在压力下保持结构"。**
> **标注**：`★★★` 面试前一周至少完整走一遍

---

## 轮次 A：技术基础轮（40 分钟）

:::card 出题顺序与节奏
| 时间 | 内容 | 考察点 |
|---|---|---|
| 0–3 min | 自我介绍 | 结构是否清晰、能否一句话定调 |
| 3–10 min | Transformer / 注意力 / KV cache | 基础是否扎实（4.1、4.4） |
| 10–18 min | 后训练（SFT/DPO/GRPO） | 是否只会背名词（3.1–3.3） |
| 18–26 min | RAG（链路、检索、评测） | 是否有系统观（5.1–5.5） |
| 26–34 min | Agent（ReAct、工具、Memory、评测） | 是否只会说框架名（6.1–6.6） |
| 34–40 min | 手撕一题 | 白板能力（7.1） |
:::

:::card 追问脚本（按这个顺序问，层层加深）
1. 「Attention 为什么除以 √d？」→ 答完后追「不除会怎样？用方差解释」
2. 「KV cache 大小怎么算？」→ 答完追「那 8B 模型 8k 上下文的 KV 大概多少？」（要能报 ~1GB）
3. 「DPO 为什么不需要 reward model？」→ 答完追「那为什么还需要 reference model？」
4. 「GRPO 和 PPO 的区别？」→ 答完追「组内奖励全相同会怎样？」
5. 「RAG 效果不好你先查什么？」→ 答完追「怎么判断是检索问题还是生成问题？」
6. 「怎么评测一个 Agent？」→ 答完追「pass@k 和 pass^k 有什么区别？」
7. 「手撕一下 attention」→ 写完追「mask 用 0 会怎样？」
:::

:::card 这轮的扣分点（自查）
- ❌ 只答结论不给理由（如"DPO 不需要 RM"但说不出为什么）
- ❌ 复杂度/数字说错（`O(n²)` 而不说 `d`；KV cache 说成几十 GB）
- ❌ 术语张冠李戴（MQA 说成省算力、MLA 说成减少头数）
- ❌ 手撕时不说边界（mask、数值稳定、整行全遮为 -inf）
:::

## 轮次 B：项目深挖轮（40 分钟，**最关键**）

:::card 出题顺序
| 时间 | 内容 |
|---|---|
| 0–3 min | 「讲讲你最有挑战的项目」 |
| 3–15 min | 顺着讲的内容往下挖（至少挖三层） |
| 15–28 min | 换一个项目，同样挖三层 |
| 28–35 min | 「你个人具体做了什么」 |
| 35–40 min | 「最大的不足」「如果重做会怎么改」 |
:::

:::card 三层追问模板（面试官一般这样挖）
**第一层（是什么）**：「你的方法具体怎么做的？」
**第二层（为什么）**：「为什么这么设计？不这样会怎样？」
**第三层（反事实/细节）**：「那 α 是多少？」「去掉这项掉多少？」「最强的 baseline 多少分？」「你们 6 个案例对了几例？」

**准备要求**：**每一层都要能立刻答**。第三层是最容易露馅的，必须提前把数字背准（见 2.4 的口径总表）。
:::

:::card 这轮的扣分点
- ❌ 说"我们"（面试官立刻会问"那你做了什么"）
- ❌ 数字含糊（"提升了大概十来个点"）
- ❌ 把案例研究说成"全对了"（RePref-Fact 是 6 个难例救回 3 个）
- ❌ 一被质疑就改口（应该：接受质疑 → 主动指出更深的局限 → 划清证据边界）
:::

:::card 救场三句话（背下来）
**数字说错被指出**：
> 「抱歉，我把两个数记混了 —— 准确值应该是 X，我刚才说的是 Y 那个骨干下的数。」

**完全不会概念**：
> 「这个概念我没系统学过，我的理解是 A，不确定对不对；如果是 B 的话，那我刚才那部分要重新想。您能说一下正确方向吗？」

**被质疑方法没价值**：
> 「这个质疑我接受，我补充一个我自己也想过的点：它真正的局限是 X。我现在的证据只能支持到 Y，再往上我没有实验。」
:::

## 轮次 C：交叉 + 行为轮（20 分钟）

:::card 交叉追问（考"有没有体系"）
1. 「你三个项目是不是同一件事换个说法？」
2. 「你的偏好学习能用到投毒检测上吗？」
3. 「CausalPoison 的破坏-修复能用在事实核查上吗？」
4. 「你做攻击研究，那怎么防？」
5. 「为什么先做判别、再做检索、最后做安全？」

> 这五题的答案都在 **2.4 §2**，要能一口气说完。
:::

:::card 行为与动机（考"稳不稳"）
| 问题 | 答题要点 |
|---|---|
| 为什么投我们公司/这个岗 | 说清**岗位要什么 + 你有什么**，不要只夸公司 |
| 你的最大不足 | 给**真不足**（无工业级经验）+ 在补什么 |
| 遇到过最大的困难 | 用项目里的真事（如"实验不收敛，最后定位到 mask"） |
| 和导师/同学有分歧怎么办 | 用"用数据说话"的实例 |
| 五年规划 | 说清"想把模型能力做成可交付系统"，别空谈 |
| 你有什么问题问我们 | 从 2.4 §5 的五个反问里挑 2 个 |
:::

## 面试当天：15 分钟速览卡

:::card 出门前按顺序过这五块（只看这个）
**① 三套串讲（3 分钟）**
- 60 秒版：判得准（RePref-Fact）→ 查得到（多智能体）→ 扛得住（CausalPoison）
- 钩子版：抛"参考模型必须冻结"这个细节

**② 数字口径（3 分钟，只看加粗的）**
- RePref：95.04 / 85.81 / 86.56 / 93.96；+2.65/+14.85/+7.53/+11.13 → 平均 **9.0pp**；20% 数据 vs SFT **+8.86pp**；消融 −2.51/−1.78/−1.66；β=0.2、τ=0.3
- CausalPoison：ASR 0.98/1.00/0.92/0.96 → **96.5%**；vs PoisonedRAG **+8.5pp**；Complete Success **88.25% vs 57.75%**；Break Failure **6/4/2/10%**
- ⚠️ 68.2% 和 95.0→23.0 **论文里没有**，别说

**③ 最危险的 10 题（2 分钟）**
68.2% 分子分母 / 9.0pp 怎么算 / 这不就是 DPO 吗 / 你个人做了什么 / α、γ 多少 / 投在哪个会 / 能落地吗 / 案例全对了吗 / 24 中 21 那 3 个呢 / 互信息是 MINE 吗

**④ 三个必答公式（2 分钟，白板默写一遍）**
- Attention：`softmax(QK^T/√d_k)V`
- KV cache：`2×layers×n_kv×d_head×seq×batch×bytes`
- DPO：`−log σ(β[(logπ_θ(y_w)/π_ref(y_w)) − (logπ_θ(y_l)/π_ref(y_l))])`

**⑤ 心态与纪律（5 分钟）**
- 先给结论再展开；每个回答留一个钩子
- 不知道就说不知道 + "我会怎么查"
- 被质疑：接受 → 主动指出更深的局限 → 划清证据边界
- **不要再学新东西**（加深印象 > 学新知识）
:::

## 面试后：30 分钟复盘模板

:::card 复盘要写这五行
```
1. 被问到的（列全，越具体越好）
2. 答砸的（写清"卡在哪一步"：想不起来 / 说不清 / 说错了）
3. 面试官追问最深的那一层是什么（这是下次的准备重点）
4. 下次改进的一句话策略
5. 需要补进速览卡的数字/结论
```
**为什么重要**：第 3 行最有价值 —— 它告诉你**自己知识的边界在哪**。连续三家都挖到同一层，那就是下次的必补点。
:::

## 自测（走完三轮后回答）

:::qa 你能在 60 秒内说完三项目主线吗
判得准（RePref-Fact，模型侧）→ 查得到（多智能体检索，系统侧）→ 扛得住（CausalPoison，评估侧）。
:::

:::qa 第三层追问最容易被挖穿的是哪几个数字
per-dataset 分数、消融掉点、最强基线是谁、案例对了几例、α/γ 取值。
:::

:::qa 被质疑方法没价值时的三句话结构
接受质疑 → 主动指出更深的局限 → 划清"我的证据只能支持到哪"。
:::

:::qa 出门前最不该做的一件事
学新知识。应该只做记忆强化（串讲 + 数字 + 公式）。
:::
