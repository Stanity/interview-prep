## 1. 30 秒口述版（背下来）

:::card 30 秒版
「我的第一篇工作是把**事实核查**从"直接预测标签"重构成**标签空间上的相对偏好学习**。

论文里我把问题归到两个来源：一是现有 LLM 方法都在做 pointwise 分类，**独立地优化 gold label**，没有显式建模它相对竞争标签的优势，所以决策边界附近的样本分不开；二是标准预测目标产出的表示**既保不住标签相关的事实信息，也没有清晰的类间分离**。

我的做法是：用**冻结的参考模型**给出标签间的相对优势作为基线，构造偏好 gap，让模型去扩大"正确标签相对竞争标签"的间隔；同时在表示层加两个互补目标——**标签 embedding 原型的互信息对齐**（保住标签相关信息）和**监督对比学习**（类内紧凑、类间可分）。

在 FEVEROUS、HoVer、SciFact、RAGtruth 四个数据集上，Macro-F1 相比**最强基线**平均高 **9.0 个点**；HoVer 上 85.81 vs 最强基线 70.96，RAGtruth 上 86.56 vs 79.03。低资源只用 20% 训练数据时，比 SFT 高 **8.9 个点**。工作被 SMC 2026 录用，我是第一作者。」
:::

**注意这句话的分寸**："相比**最强基线**平均高 9.0 个点" —— 这是你四个数据集上"vs 各自最强基线"的提升平均值（2.65 / 14.85 / 7.53 / 11.13 → 9.04）。说清口径，避免被追问时被动。

## 2. 3 分钟版（项目深挖轮主线）

1. **任务**（20s）：输入 `x = (claim, evidence)`，输出 `y ∈ Y = {Supported, Refuted}`。
2. **痛点**（30s）：支持/反驳样本常**只在少数决定性线索上不同**（数字、实体、时间、否定），论文称为 **label boundary ambiguity**。
3. **现有方法的两处不足**（40s，**这是论文原文的框架，直接用**）：
   - ① **目标层面**：pointwise 分类独立优化 gold label，没有显式约束"gold 相对竞争标签的间隔"，边界附近不稳；
   - ② **表示层面**：标准目标产出的表示既不保留足够的标签相关事实信息，也不保证清晰的类间分离。
4. **我的重构**（30s）：把"预测标签"换成"**在标签空间上做相对比较**"——不问概率多少，问**gold 比竞争标签好多少**，且以冻结参考模型为基线。
5. **方法三件套**（50s）：`L_pref`（输出层，扩间隔）+ `L_MI`（表示层，标签 embedding 原型对齐）+ `L_SCL`（表示层，几何分离）。
6. **实验**（30s）：11 个方法对比（10 基线 + 我们）、4 数据集、2 骨干、消融、低资源、标签噪声、超参热力图、t-SNE、案例研究。

## 4. 问题定义（论文的两个"source"要能背）

:::card 为什么难：两个来源（论文 Introduction 原话的逻辑）
**来源一：目标函数层面**
大多数 LLM 方法把核查形式化为 direct label prediction，**独立优化 gold label**，不显式建模它相对竞争标签的相对优势。这种监督对"决策边界附近的样本"不够。

**来源二：表示层面**
标准预测目标产出的表示有两个问题：
- 不能保留足够的 **label-relevant factual information**（标签相关的事实信息）
- 不能保证清晰的 **class-wise separation**（类间分离）

**所以解法必须同时动"目标"和"表示"** —— 这正是 `L_pref` + `{L_MI, L_SCL}` 的设计来由。
:::

**面试话术**：「如果我们只改目标函数，表示可能还靠捷径；只改表示，边界又没被拉开。所以我做的是一个"目标 + 表示"的双层改造。」

## 5. 方法：逐个公式讲（这节必须能白板复现）

### 5.1 任务形式化

`x = (claim, evidence)`，`y ∈ Y = {Supported, Refuted}`（**二分类**，没有 NEI）。模型是 causal LM backbone `fθ`，对标签打分为 `sθ(x, y)`。

> **常见错误**：有人会顺口说"三类（含证据不足）"。你的论文是**二元**设定，别说错。

### 5.2 标签空间相对偏好学习（公式 1、2）

:::card 偏好对怎么来 + 两个公式
**偏好对构造**：每个训练样本 `(x, y⁺)`，把 gold label 当 preferred，把 `Y \ {y⁺}` 里另一个当 competing，记作 `y⁻`。二分类下**每个样本自然诱导一个偏好对** `(y⁺, y⁻)`。

**公式 (1) — 偏好 gap**：
```
δθ(x) = [ sθ(x, y⁺) − sθ(x, y⁻) ] − [ s_ref(x, y⁺) − s_ref(x, y⁻) ]
```
- 前半：**当前模型**给出的标签间优势
- 后半：**冻结参考模型** `s_ref` 给出的标签间优势（= 这个实例的难度基线）
- 相减 = **对实例难度做归一化**：参考模型本来就分得开的，不用再费力；参考模型也分不开的（难例），才是训练的重点

**公式 (2) — 偏好损失**：
```
L_pref = − log σ( β · δθ(x) )
```
- `β > 0` 控制偏好学习的锐度（论文最优 `β = 0.2`）
- 最小化它 ⟺ **最大化"相对参考模型的标签间对数间隔"**
:::

**为什么参考模型必须冻结**（追问必到）：不冻结的话基线在动，模型可以靠**压低 `s_ref(x, y⁺)`** 来制造"相对优势"，而不是真的提升自己 —— 目标漂移。

### 5.3 表示增强之一：显式互信息对齐（公式 3–6）

:::card 机制（这块我上一版写粗了，这是论文真实做法）
**目标**：让表示 `h(x)` 保留"能预测 veracity label"的信息。

**关键设计**：引入**可学习的标签 embedding** `E ∈ R^{|Y|×d_e}`，`e_y` 是标签 `y` 的 embedding。用"表示 ↔ 标签原型"的兼容度做 InfoNCE。

**公式 (3) — 投影网络**：把 `h_i` 映射到与标签 embedding 相同的语义空间
```
gϕ(h_i) = W2 · ReLU(W1 · h_i)
```

**公式 (4) — 归一化点积的兼容度**（normalized prototype based compatibility）
```
Tϕ(h_i, e_y) = ⟨ gϕ(h_i)/‖gϕ(h_i)‖₂ ,  e_y/‖e_y‖₂ ⟩
```

**公式 (5) — 温度缩放**
```
z_{i,y} = Tϕ(h_i, e_y) / τ_m
```
`τ_m` 小 → 分布更集中、对齐更强；`τ_m` 大 → 监督更平滑、防止过度自信。

**公式 (6) — InfoNCE 形式的互信息下界**
```
L_MI = − (1/N) Σ_i  log [ exp(z_{i,y_i}) / Σ_{y∈Y} exp(z_{i,y}) ]
```
:::

**一句话**：「互信息这一项本质是"**让表示更像它自己的标签原型、不像别的标签原型**"，用 InfoNCE 下界去逼近互信息。」

> 术语要对：不是"判别器网络 f(z,y)"，而是 **label embedding 原型 + 兼容度打分**。被追问"你的互信息估计器长什么样"时，答"投影 MLP + 标签 embedding 的归一化点积 + 温度"，别答成 MINE。

### 5.4 表示增强之二：监督对比学习（公式 7–9）

:::card 机制
**目标**：类内紧凑 + 类间可分（互信息管"有没有信息"，对比管"排成什么形状"）。

**公式 (7)(8) — 归一化 + 温度缩放相似度**
```
h̃_i = h_i / ‖h_i‖₂
s_ij = (h̃_iᵀ h̃_j) / τ_c
```

**公式 (9) — 监督对比损失**
```
L_SCL = Σ_i  −(1/|P(i)|) Σ_{p∈P(i)}  log [ exp(s_ip) / Σ_{a∈A(i)} exp(s_ia) ]
```
- `P(i)`：**mini-batch 内与 i 同标签**的样本（这就是"监督"的含义，不靠数据增强）
- `A(i)`：mini-batch 内**除 anchor 外所有样本**（含 P(i)），做分母
- `τ_c`：温度，越小越关注难正/难负样本
:::

**两项目标的分工（一句话答法）**：
> 「`L_MI` 保证表示里**留住标签信息**（防捷径），`L_SCL` 保证表示**几何可分**（防纠缠）。论文里明确说它们从互补视角增强表示：前者是 representation-label alignment，后者是 class-wise clustering。」

### 5.5 总目标与推理（公式 10、11）

```
L_total = L_pref + α · L_SCL + γ · L_MI          (10)
ŷ = argmax_{y∈Y} sθ(x, y)                        (11)
```

:::card ⚠️ 面试注意
**`α` 给 `L_SCL`、`γ` 给 `L_MI`** —— 顺序不要和"先互信息后对比"的叙述搞混。
论文正文**没有披露 α、γ 的具体取值**（只给了 β=0.2、τ=0.3 的热力图分析）。如果被问：
- 记得真实值 → 直接报
- 不记得 → 诚实说「α、γ 是按量级调的，论文里重点做了 β 和 τ 的敏感性分析」，**不要编数字**
:::

### 7.5 超参敏感性（Fig.2 热力图）

- 最优：**β = 0.2，τ = 0.3**（在 HoVer 和 SciFact 两个数据集上做的热力图）
- β 太小 → 偏好信号不足；β 太大 → 偏好过强 → 性能下降
- τ 不合适 → 削弱表示的判别结构

**话术**：「论文对 β 和 τ 做了热力图分析，两者都表现出**中等敏感**：在最优值附近是一个平台区，说明方法对超参不是特别挑。」

:::card 这张表怎么用（诚实版，别说过头）
**能说的**：

2. 更明显的是 **margin 的绝对值**：SFT 都在 **0.23 ~ 0.77** 之间（几乎贴着决策边界），RePref-Fact 在 **17.68 ~ 36.41**（决策非常果断）；

- ❌ "我们在这些案例上都对了"（错，还错了 3 个）

**加分说法**：「#1、#5 这两个仍错的例子恰好说明一个诚实的局限——当关键实体关系需要**外部知识**才能连起来时，扩大间隔解决不了问题，需要检索或知识注入。」

## 8. 与 DPO 的区别（**必被追问，五条背熟**）

:::card 五条区别（现在有公式细节支撑，答得更硬）
| 维度 | DPO（标准用法） | RePref-Fact |
|---|---|---|
| **偏好对来源** | 同一 prompt 下两个**回答**（chosen / rejected），需要偏好标注 | 同一实例下两个**标签假设** `(y⁺, y⁻)`，二分类下**每个样本自动诱导一个偏好对**，不需要偏好标注 |
| **比较空间** | 全词表上的序列 logprob | **标签分数** `sθ(x, y)`（判别式） |
| **参考模型的作用** | KL 约束，防止偏离 SFT 分布 | 公式 (1) 里提供**标签间优势的基线**，做**实例难度归一化** |
| **额外目标** | 无 | 多了 `L_MI` + `L_SCL` 两个**表示层**目标（DPO 没有） |
| **任务性质** | 生成（让模型偏好好回答） | 判别（让模型偏好正确标签），推理是 `argmax_y sθ(x,y)` |
:::

**被问"这不就是 DPO 吗"**：
> 「公式 (2) 的 log-sigmoid 结构确实借了 DPO 的形式，但三处不同：**偏好对是标签而不是回答**、**参考模型用来做难度归一化而不是 KL 约束**、而且我在表示层加了互信息和对比两个目标 —— DPO 只改输出目标，我改的是"目标 + 表示"。」

## 9. 十三个刁钻追问预答

:::qa 你的两个"source"具体指什么？为什么必须同时解决
① **目标层面**：pointwise 分类独立优化 gold label，不建模相对优势 → 边界附近不稳；
② **表示层面**：表示既不保留足够的 label-relevant 事实信息，也没有清晰类间分离。
只改目标，表示可能靠表层捷径（分数上去了但学的东西不对）；只改表示，判别边界没被显式拉开。所以必须"目标 + 表示"一起动。
:::

:::qa 参考模型为什么冻结？不冻结会怎样
不冻结时基线 `s_ref` 在动，模型可以靠**降低参考模型对 gold 的分数**来让 `δθ(x)` 变大，而不是真的提升自己 —— 目标漂移，等价于 reward hacking。冻结后 `δθ` 才真正等价于"扩大本模型的标签间隔"。
:::

:::qa 二分类下每个样本只有一个偏好对，监督信号够吗
够，而且是"同量级"的：
- 偏好项：每样本 1 对（`y⁺` vs 唯一的 `y⁻`）
- 但 `L_SCL` 是在 **mini-batch 内**做对比（batch = 16，梯度累积 4），每个 anchor 有多个正样本与负样本；`L_MI` 是在**标签原型**上做 InfoNCE（`|Y| = 2`，但每个样本都贡献一项）
所以三项不是都靠"偏好对"吃饭。
:::

:::qa 你的互信息估计器具体是什么结构？是 MINE 吗
不是 MINE 的判别器网络，而是**归一化原型（prototype）式的兼容度**：
`gϕ(h) = W2·ReLU(W1·h)` 投影 → 与可学习标签 embedding `e_y` 做归一化点积（公式 4）→ 除以温度 `τ_m`（公式 5）→ 用 **InfoNCE 形式的下界**（公式 6）。
本质是"让表示更像自己的标签原型、不像别人的"。
:::

:::qa 为什么 `L_MI` 和 `L_SCL` 都需要？它们作用在哪一层
都是**表示层**，但目标不同：
- `L_MI`：**表示–标签对齐**（representation-label alignment），保证信息留住；
- `L_SCL`：**类间结构化**（class-wise clustering），保证几何可分。
论文原话是"从互补视角增强表示"。消融也证明各自都贡献（−1.78 / −1.66），掉点分布还不同：`L_MI` 在 HoVer/RAGtruth 掉得多（这两个更依赖事实信息）。
:::

:::qa α 和 γ 的取值是多少
（🟡 论文正文未披露）**真实答法**：「β 和 τ 我做了热力图（最优 0.2 和 0.3），α、γ 是按损失量级调的，论文里没有作为重点分析。」
**不要说具体数字**，除非你确认记得。
:::

:::qa 平均 9.0pp 是不是挑了数据集？最强基线是谁
不是挑的，四个数据集都提升了，只是幅度不同：
| 数据集 | 最强基线 | 我们 | 提升 |
|---|---|---|---|
| FEVEROUS | BiDeV 92.39 | 95.04 | +2.65 |
| HoVer | BiDeV 70.96 | 85.81 | +14.85 |
| RAGtruth | LettuceDetect 79.03 | 86.56 | +7.53 |
| SciFact | CORRECT 82.83 | 93.96 | +11.13 |

9.0 是这**四个提升值的算术平均**。提升小的是 FEVEROUS，因为 LLM 基线在该数据集本来就强（BiDeV 92.39）；提升大的是 HoVer（多跳 +14.85）和 SciFact（+11.13）。
:::

:::qa 为什么不用 Accuracy，用 Macro-F1
四个数据集类别不均衡，Accuracy 会被多数类主导。Macro-F1 对每类等权，能反映**难类**的表现，对"边界是否真的稳"更敏感。这也是 HoVer 分解成 2-hop / 3-hop / 4-hop 分别报的原因 —— 越难的 hop 越能看出差距。
:::

:::qa 低资源下优势更大，是不是因为方法带了强正则
两者都有，但能拆开：
1. **表示层两项确实起正则作用**，小数据受益；
2. 但如果是纯正则，全量数据下收益应该收敛 —— 实际全量仍然领先（HoVer 85.81 vs SFT 81.22 = +4.59），说明收益来自**目标形态的改变**（优化间隔）而不只是正则。
数据支撑：20% 时 +8.86，全量时 +4.59，**趋势是"数据越少优势越大"**。
:::

:::qa 标签噪声实验怎么做的？为什么噪声越大优势越明显
随机翻转 HoVer 训练标签的 **20% / 10% / 5%**。
噪声 20% 时：77.65 vs SFT 67.09（+10.56）；噪声 5% 时：83.75 vs 76.25（+7.50）。
原因：`L_pref` 用冻结参考模型做基线，相当于给监督信号一个"参照系"，噪声标签造成的偏移会被部分抵消；`L_SCL` 又利用了 batch 内的标签结构，单个错误标签的影响被稀释。
:::

:::qa 换更大的骨干还成立吗
已验证 8B 级两个不同骨干（Qwen3-8B、Llama-3.1-8B），结论一致：Ours 在两个骨干上分别是 94.85/85.59/85.83/93.12 和 95.04/85.81/86.56/93.96，都明显高于对应 SFT（如 HoVer 80.74 / 81.22）。
更大的模型没做实验（如实说）。判断：模型越大表层捷径越少，SFT 基线会变强，相对收益可能缩小，但"相似样本判别"这个问题不会消失。
:::

:::qa 案例研究里你们的 margin 大很多，这能说明什么
能说明**决策更果断**，但不能直接说明"更准"。诚实版本：
- SFT 在 6 个难例上**全错**，我们**救回 3 个**；
- margin 从 **0.23~0.77** 提升到 **17.68~36.41**，说明不再贴着决策边界；
- 但我们仍有 3 个错，其中 2 个是"很果断地错"（#1、#5），这说明**外部知识缺失**是扩大间隔解决不了的问题。
:::

:::qa 你这个方法最大的局限
三条（照实说，每条都有依据）：
1. **依赖已知标签空间**：只有 `{Supported, Refuted}` 二元时偏好对最自然；标签集合更大或开放时，偏好对的构造需要重新设计；
2. **竞争标签是"均匀"的**：现在把 `Y\{y⁺}` 当竞争标签，没有区分"哪些竞争标签更难"（比如有的反驳只是证据不足）→ 如果按难度加权，难例间隔会拉得更开；
3. **外部知识缺失时无法解决**：案例 #1/#5 说明，需要多跳连接外部实体关系时，仅扩大间隔不够，需要检索增强。
**收尾**：「第 2 条是我下一步最想做的。」
:::

## 12. 自测（合上文档，60 秒答完每题）

:::qa 论文把问题归到哪两个来源？分别对应你哪个设计
① 目标层面：pointwise 分类不建模相对优势 → 对应 `L_pref`（公式 1、2）；
② 表示层面：不保留 label-relevant 事实信息、无清晰类间分离 → 对应 `L_MI`（信息）和 `L_SCL`（几何）。
:::

:::qa 写出偏好 gap 和偏好损失，并解释每一项
`δθ(x) = [sθ(x,y⁺) − sθ(x,y⁻)] − [s_ref(x,y⁺) − s_ref(x,y⁻)]`
`L_pref = −log σ(β·δθ(x))`
第一项是当前模型的标签间优势，第二项是冻结参考模型的标签间优势（难度基线），相减 = 难度归一化；σ 是 sigmoid，β 控锐度。
:::

:::qa 互信息项和对比项分别解决什么问题？为什么不能只留一个
`L_MI`（标签 embedding 原型 + InfoNCE）解决"表示里有没有标签信息"，防表层捷径；`L_SCL`（SupCon）解决"表示排成什么形状"，防类内散/类间近。
只留 `L_MI`：有信息但几何纠缠；只留 `L_SCL`：几何漂亮但可能丢细粒度事实。消融显示两者各自都掉 1.6~1.8 个点。
:::

:::qa 平均 9.0 个点怎么算出来的？四个数据集分别提升多少
（2.65 + 14.85 + 7.53 + 11.13）/ 4 = 9.04。分别是 FEVEROUS +2.65、HoVer +14.85、RAGtruth +7.53、SciFact +11.13，都是对比各自最强基线。
:::

:::qa 8.9 个点是在什么设置下、对比谁
HoVer 数据集，只用 **20% 训练数据**，对比 **SFT**：74.70 vs 65.84 = +8.86。同设置下全量是 85.81 vs 81.22 = +4.59，所以"数据越少优势越大"。
:::

:::qa 案例研究里你们 6 个难例对了几个？能说明什么
救回 3 个（SFT 全错）。更能说明问题的是 margin：SFT 在 0.23~0.77（贴边界），我们在 17.68~36.41（果断）。但仍有 3 个错，其中 2 个是"果断地错"，说明外部知识缺失时扩大间隔不够。
:::
