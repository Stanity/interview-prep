## 1. 30 秒口述版（背下来，任何面试都用这个开场）

:::card 30 秒版（照念即可）
「我的第一篇工作是把**事实核查**从"分类问题"重构成**标签空间上的相对偏好学习**。

原来的做法是让模型直接预测标签，但支持和反驳这两个标签的样本**语义高度相似**——差别常常只在数字、实体、时间或者一个否定词上，所以模型的判别边界很不稳。

我的做法是：用**冻结的参考模型**在同一个实例上构造"正确标签相对竞争标签"的偏好对，显式扩大它们之间的评分间隔；同时从表示层加了两项约束——**互信息对齐**保证表示里保住标签相关信息，**监督对比学习**保证类内紧凑、类间可分。

结果是在四类事实核查数据上，Macro-F1 比同期方法平均高 **9.0** 个点，在只用 20% 训练数据的低资源设定下比同期微调方法高 **8.9** 个点。工作被 SMC 2026 录用，我是第一作者。」
:::

**为什么这个开场有效**：一句话给问题、一句话给方法、一句话给结果。面试官听完就能决定往哪个方向追问，你也就掌握了主动权。

## 2. 3 分钟版（项目深挖轮的主线，按这个顺序讲）

1. **场景与痛点**（30s）：事实核查要判断"给定证据，某个声明是支持还是反驳"。难点不是"懂不懂语义"，而是**支持/反驳的样本本身极度相似**。
2. **现有方法的三个不足**（40s）：
   - prompt 式：依赖模型的隐式知识，边界不可控；
   - 判别式 SFT：优化"正确标签的概率"，但**没有显式建模它相对竞争标签的优势**；
   - 检索增强式：解决"证据不够"，但没解决"证据相似时怎么分"。
3. **我的重构**（30s）：把"预测标签"换成"**在标签空间上做相对比较**" —— 不问"这个标签概率多少"，而问"正确标签比竞争标签**好多少**"。
4. **方法三件套**（60s）：相对偏好 loss（输出层）+ 互信息对齐（表示层·信息）+ 监督对比（表示层·几何）。
5. **实验**（30s）：4 类数据 × 10 个基线 × 2 个骨干；平均 +9.0pp；低资源 +8.9pp；做了消融、超参敏感性、标签噪声鲁棒性。
6. **一句话收尾**（10s）：「本质上是把**判别目标从概率改成间隔**，再在表示层补齐信息和几何两个约束。」

## 3. 问题定义：为什么要重构成"偏好"

:::card 关键事实（这些细节要能随口说出）
- 事实核查（fact verification）的输入是 `(声明 claim, 证据 evidence)`，输出是 `SUPPORTS / REFUTES`（有的数据集还有 `NOT ENOUGH INFO`）。
- **难点来源**：同一组证据下，支持和反驳版本之间常只差
  - 一个**数字**（「增长了 12%」vs「下降了 12%」）
  - 一个**实体**（「A 公司收购 B」vs「B 收购 A」）
  - 一个**时间**（「2020 年」vs「2021 年」）
  - 一个**否定词**（「有效」vs「无效」）
- 所以模型很容易学到"表层模式"（比如句子里有"增长"就判 SUPPORTS），一旦这些线索被扰动就崩。
- **这直接导致两个后果**：① 判别边界模糊（两个类的分数接近）；② 表示空间里两类纠缠在一起。
:::

> 🟡待填：准备 2–3 个你数据里的**真实例子**（claim + evidence + 两个标签版本），面试时能具体说出来。这是"你真的做过"的最强证据。

## 4. 方法谱系对照（面试官最爱问"为什么不用 X"）

| 方案 | 怎么做 | 它能解决什么 | 它解决不了什么 |
|---|---|---|---|
| **Prompt 式** | 构造提示词让 LLM 直接输出标签 | 零成本启动，泛化好 | 边界不可控、不可复现、成本高 |
| **判别式 SFT** | 加分类头 / 用标签词微调，优化交叉熵 | 有监督、稳定 | 只压低错误标签概率，**不显式扩大间隔** |
| **检索增强** | 先检索证据再判断 | 证据不足的问题 | 证据相似时仍然分不开 |
| **偏好优化（本轮工作）** | 显式比较"正确标签 vs 竞争标签" | **直接优化决策间隔** | 需要能构造标签对（标签空间要已知） |

**一句话答法**：「SFT 优化的是'正确标签的概率'，我的方法优化的是'正确标签相对竞争标签的**优势**'——后者等价于直接优化决策间隔，对相似样本更鲁棒。」

## 5. 核心机制拆解（本文最重的部分）

### 5.1 用冻结参考模型构造"标签间相对偏好"

:::card 这一步到底在做什么（讲不清这里就等于没做过）
对每个实例 `x`（claim + evidence），标签空间是 `Y`。取正确标签 `y⁺` 和一个竞争标签 `y⁻`，构造偏好对 `(x, y⁺, y⁻)`。

**关键设计**：不直接要求「`log π(y⁺|x) > log π(y⁻|x)`」，而是要求「**相对冻结参考模型**的优势变大」：

```
目标：让 [log π(y⁺|x) − log π(y⁻|x)] − [log π_ref(y⁺|x) − log π_ref(y⁻|x)] 尽可能大
```

- `π_ref` 是**冻结的**参考模型（SFT 起点 / 基座模型）。
- 右半部分 `log π_ref(y⁺|x) − log π_ref(y⁻|x)` 是**参考模型自己给出的标签间优势**，可以理解为"这个实例本身的难度基线"。
- 减去它，相当于**对实例难度做了归一化**：参考模型本来就分得很开的实例，不需要模型再费力；参考模型分不开的（难样本），模型才去重点扩大间隔。

**这就是"标签空间相对偏好"的准确含义** —— 偏好发生在**同一实例的不同标签假设之间**，基线来自**冻结参考模型**。
:::

**为什么必须冻结**：如果参考模型也一起更新，"基线"在动，目标就漂移了——模型可以通过**降低参考模型的分数**来"制造优势"，而不是真的提升正确标签。这和 DPO 里冻结 reference model 的理由是同一个。

### 5.2 相对偏好 loss 与"优化决策间隔"

:::card 从 loss 到"间隔"的推导（面试要能推，至少能讲清等价性）
用 log-sigmoid 形式的偏好损失：

```
L_pref = − log σ( β · { [log π(y⁺|x) − log π(y⁻|x)] − [log π_ref(y⁺|x) − log π_ref(y⁻|x)] } )
```

记 `Δ_π(x) = log π(y⁺|x) − log π(y⁻|x)`（当前模型的标签间**对数优势**），`Δ_ref(x)` 同理。

则 `L_pref = − log σ(β(Δ_π − Δ_ref))`。

**读法**：
- 当 `Δ_π − Δ_ref → +∞` 时 loss → 0：模型的标签间隔**明显大于**参考模型 → 满意
- 当 `Δ_π − Δ_ref → −∞` 时 loss → +∞：模型的标签间隔**还不如**参考模型 → 惩罚
- `β` 控制"要多大的优势才算够"——β 越大，越强调把间隔拉得更开（也更激进，容易过拟合）

**所以"等价于优化决策间隔"这句话的严格含义是**：loss 是关于 `Δ_π − Δ_ref` 的单调递减凸函数（对 `Δ_π`），最小化它就是在**最大化"相对参考模型的标签间对数间隔"**。
:::

**一句话答法**：「把分类的交叉熵换成 pairwise 的 log-sigmoid 之后，优化目标就从'正确标签的概率'变成了'正确标签相对竞争标签的对数间隔'，而且这个间隔是**以参考模型为基线**的。」

### 5.3 互信息对齐（表示层 · 信息视角）

:::card 它约束的是什么
**目标**：让表示 `z` 尽可能保留标签 `y` 的信息，即最大化互信息 `I(z; y)`。

**为什么需要**：光有输出层 loss 时，模型可能靠"跟标签无关的表层捷径"（比如文本长度、特定词）来降低 loss，表示本身并没有编码标签语义。互信息对齐就是**逼表示把标签信息留住**。

**怎么估**：互信息本身难算，用**神经互信息估计器**（MINE / InfoNCE 形式的变分下界）。InfoNCE 形式：

```
L_MI = − E[ log  exp(f(z, y⁺)) / Σ_{y'} exp(f(z, y')) ]
```

其中 `f` 是一个判别器（小网络），`(z, y⁺)` 是正对，`(z, y')` 是负对。**本质是在表示空间里做"这个表示对应哪个标签"的对比**。

**面试话术**：「输出层的偏好 loss 只管判别边界，管不住表示里有没有信息。互信息对齐是给表示加一个'标签可解码性'的约束，防止模型靠捷径刷分。」
:::

> 🟡待填：你用的是 MINE 还是 InfoNCE？判别器结构是什么（几层 MLP）？batch 内负样本还是额外负采样？这些必须能答。

### 5.4 监督对比学习（表示层 · 几何视角）

:::card 它约束的是什么
**目标**：同一标签的表示靠近（类内紧凑），不同标签的表示远离（类间可分）。

**标准 SupCon 形式**：

```
L_Sup = − Σ_i  (1/|P(i)|) Σ_{p∈P(i)}  log [ exp(sim(z_i, z_p)/τ) / Σ_{a≠i} exp(sim(z_i, z_a)/τ) ]
```

- `P(i)`：与 `i` 同标签的样本集合（**这就是"监督"的含义**：正样本按标签划分，不是靠数据增强）
- `τ`：温度系数，控制分布的"锐度"。τ 小 → 更关注最难的负样本；τ 大 → 更平滑。
- `sim`：余弦相似度

**和互信息的互补关系**（这是最容易被追问的一点）：
- 互信息管 **"信息有没有留下来"**（可解码性）
- 对比学习管 **"留下来的信息排成什么形状"**（几何分布）
- 两者都需要，因为"有信息但纠缠"和"分得开但没信息"都不行。
:::

### 5.5 三项怎么配平

```
L_total = L_pref + λ₁ · L_MI + λ₂ · L_Sup
```

**面试要说的三句话**：
1. **量级**：三项的数值量级不同，必须调权重（如果直接相加，某一项会主导）。
2. **敏感性**：我做了超参敏感性分析，λ 在一定区间内结果稳定，超出后性能下降（🟡待填：具体区间和你观察到的峰值）。
3. **训练顺序**：三项是**联合优化**的（不是分阶段），因为表示约束和输出约束互相影响（🟡待填：如果实际是分阶段，如实说）。

## 6. 几何解释（白板能画出来最好）

:::card 一张图讲清三项分工
```
        表示空间（2D 示意）
   ○ ○ ○              ●  ● ●
   ○  ○   ← 类内紧凑   ● ●   ← 类内紧凑
      ↕ 类间远离（SupCon 管几何）
   ○ ○ ○        ▲▲▲        ● ● ●
                  ↑
           输出层：偏好 loss 管"分界线在哪、间隔多宽"
           互信息：管"这些点里到底有没有标签信息"
```
- **偏好 loss**：决定**分界面的位置与间隔宽度**（输出层）
- **SupCon**：决定**点的分布形状**（类内聚、类间远）
- **互信息**：决定**点里是否保留了标签语义**（防止捷径）
:::

**话术**：「三项不是三个 trick 叠加，而是分别管**判别、几何、信息**三件事，缺一个都会出现特定的失败模式——只有偏好 loss 会用捷径，只有对比会丢信息，只有互信息则边界不够宽。」

## 8. 消融实验怎么讲（不是背数字，是讲"为什么少了这一项会掉"）

:::card 消融的讲法模板（按这个结构说，即使具体数字忘了也不会崩）
| 去掉什么 | 预期会掉在哪 | 为什么 |
|---|---|---|
| 去掉偏好 loss，只留对比+互信息 | 整体都掉，**相似样本掉最多** | 表示层做好了，但判别边界没被拉开 |
| 去掉互信息 | 低资源和噪声条件下掉得更多 | 表示丢了标签信息，靠捷径的模型在数据少/脏时最先崩 |
| 去掉对比 | 类间可分性下降，**易混类别掉最多** | 表示几何纠缠，边界再好也会串 |
| 只用交叉熵（全去掉） | 相当于基线 SFT | 这正是"现有方法"的问题所在 |

**一句话总结**：「三项的收益不是可加的，而是**各自对应一种失败模式**：偏好 loss 治"分不开"，互信息治"没信息靠捷径"，对比治"纠缠"。」
:::

> 🟡待填：四项消融的**具体掉点数字**。写不出精确值时，说"去掉 X 掉 N 个点左右，其中最明显的是某某条件"也比含糊过去强。

## 9. 与 DPO 的五个不同（**必然被追问**，必须背熟）

:::card 一定要背下来的五条区分
| 维度 | DPO（标准用法） | 我的 RePref-Fact |
|---|---|---|
| **偏好对的来源** | 同一个 prompt 下两个**回答**（chosen / rejected，来自人类或 AI 反馈） | 同一个实例下两个**标签假设**（正确标签 vs 竞争标签） |
| **数据需求** | 需要**偏好标注数据** | 只需要**普通监督标签**，偏好对可自动构造 |
| **参考模型的作用** | 做 KL 约束，防止偏离 SFT 分布太远 | 提供**标签间优势的基线**，用于实例难度归一化 |
| **比较的对象** | 全词表上的序列 logprob | 标签词 / 标签模板上的 logprob（判别式） |
| **任务性质** | 生成（让模型更偏好"好回答"） | 判别（让模型更偏好"正确标签"） |
:::

**被问"这不就是 DPO 吗"时的标准答法**：
> 「形式上确实借用了 DPO 的 log-sigmoid 结构，但我做的是**判别任务上的标签空间偏好**：DPO 是'两个回答谁更好'，我是'两个标签谁更对'；而且我的偏好对是**从监督标签自动构造**的，不需要偏好标注。参考模型的角色也不同——DPO 用它约束 KL，我用它做**实例难度归一化**，这是让相似样本能被区分开的关键。」

## 10. 12 个刁钻追问预答

:::qa 为什么不直接用 DPO 训这个任务，非要自己设计
两个原因：
1. **数据形态不同**：DPO 需要 `(prompt, chosen, rejected)` 的偏好数据，而事实核查只有"这个实例的正确标签"，没有"哪个回答更好"的人工偏好。我要用监督标签**自动构造**标签间的偏好对。
2. **目标不同**：DPO 优化的是"生成更被偏好的回答"，我要优化的是"判别的决策间隔"。所以我在 DPO 的结构上加了两项**表示层**约束（互信息和对比），这是 DPO 没有的。

一句话：「结构借用了 DPO，问题定义和数据构造是我自己的。」
:::

:::qa 参考模型为什么要冻结？不冻结会怎样
不冻结的话，"基线"本身在变。模型可以靠**压低参考模型给出的正确标签分数**来制造"相对优势"，而不是真的提升自己——这就是目标漂移（reward hacking 的一种）。
冻结之后，`Δ_ref` 是一个固定常数，loss 才真正等价于"扩大本模型的标签间隔"。
:::

:::qa 标签只有两三个，偏好对数量够训练吗
够，而且比想象的多：每个实例可以构造 `|Y| − 1` 个偏好对（正确标签 vs 每个竞争标签）。四类数据加起来，偏好对数量是实例数的 1–2 倍，和原始监督信号同量级。
更重要的是**这三项 loss 不都需要偏好对**：互信息和对比学习用的是实例级表示，不受标签对数限制。
:::

:::qa 互信息估计的方差很大，你怎么控制
（🟡待填：按你的实际做法答）通用答法有三条：
1. 用 **InfoNCE 形式**（有界、方差比 MINE 小）而不是直接估 MINE；
2. 判别器**容量不要太大**，否则会"记住"batch 而不是学映射；
3. 用**较大的 batch** 提供更多负样本，或维护一个负样本队列。
:::

:::qa 对比学习的正样本怎么定义？batch 内的同类够吗
正样本 = **同标签**的其它实例（这就是 SupCon 的"监督"含义，不靠数据增强）。
batch 内同类样本数量取决于类别比例，类别不均衡时会偏少 → （🟡待填：你是否用了类平衡采样 / 更大的 batch / memory bank）。
:::

:::qa 三项 loss 的权重怎么定？敏感吗
（🟡待填：给出你的搜索范围和最终取值）
答题结构：「先固定另外两项、单项扫一遍确定量级，再小范围联合搜。敏感性分析显示在 🟡待填 区间内结果稳定，超出后开始下降——下降的原因分别是：λ₁ 太大 → 表示被互信息约束主导，判别变差；λ₂ 太大 → 过度压缩类内，反而丢细粒度线索。」
:::

:::qa 平均 +9.0pp 是不是 baseline 太弱
我们的 baseline 包含**同期方法在相同设置下的复现**（不是照抄论文数字），并且对比了 prompt 式和 SFT 式两类。最强基线是 🟡待填，它在 🟡待填 数据集上其实很强，我们的提升主要来自 🟡待填。
另外低资源（20% 数据）下 +8.9pp 这个结论更能说明问题：**数据越少，显式建模间隔的收益越大**，这不是"baseline 弱"能解释的。
:::

:::qa 为什么用 Macro-F1 而不是准确率
因为四类数据里类别分布不均衡，Accuracy 会被多数类主导。Macro-F1 对每个类等权，能反映**小类（往往也是难类）**的表现，这对"判别边界是否真的稳"更敏感。
🟡待填：如果有 micro-F1 或 per-class F1，可以补一句"小类提升最明显，说明不是靠多数类刷分"。
:::

:::qa 20% 低资源下提升更多，会不会是因为你的方法参数更少/正则更强
不是同一个原因，可以这样拆：
1. 三项 loss 里有两项是**表示层约束**，本质上起到了强正则的作用，小数据时确实受益；
2. 但如果是纯正则，全量数据下收益应该收敛甚至变负，而我们在全量数据下仍有提升 → 说明收益来自**目标函数形态的改变**（优化间隔），不只是正则。
🟡待填：如果你有"全量 vs 20%"的对比表，直接报两个数最有说服力。
:::

:::qa 标签噪声鲁棒性是怎么造出来的
（🟡待填：常用做法是**按比例随机翻转标签**，例如 10%/20%/30%；也可以做"只翻转相似类的标签"这种更难设定。）
答题要点：「我做了对称噪声和非对称噪声（只在支持/反驳之间翻）两种设定，后者更难，因为它正好攻击我们最关心的边界。」如果你只做了对称噪声，就如实说。
:::

:::qa 换成更大的骨干（比如 32B）还成立吗
诚实回答 + 给出判断依据：
「我验证了 8B 级别的两个不同骨干（Qwen3-8B 和 Llama-3.1-8B），结论一致，说明方法不依赖特定模型的 tokenizer 或训练细节。更大的模型我没有实验（🟡按实际说），但我的判断是：模型越大，**表层捷径越少**，所以纯 SFT 的基线会变强，相对收益可能缩小；不过"相似样本判别"这个问题本身不会消失。」
**不要**说"一定能提升"——没有实验就说没有。
:::

:::qa 能不能端到端训练，不做 LoRA
可以，但没必要：
1. 我的贡献在**目标函数与表示约束**，不在参数规模，LoRA 足够验证；
2. 全参微调在 8B 上代价高，且更容易在小数据上过拟合，会干扰对方法本身的判断。
🟡待填：如果有全参微调的对比实验，报数字；没有就说明"这是我下一步想补的"。
:::

:::qa 你这个方法最大的局限是什么
三条诚实且不致命的局限：
1. **依赖标签空间已知**：开放式事实核查（标签事先不明确）时，构造偏好对的方式要改；
2. **偏好对是启发式构造的**：正确 vs 竞争，没有考虑"哪些竞争标签更难"（比如"反驳"里还分"直接反驳"和"证据不足"）；
3. **三项权重需要调**：虽然不敏感，但换数据集还是要搜一次。
**收尾要说**：「第 2 条是我最想改的——如果能按难度对竞争标签加权，难样本的间隔会被拉得更开。」
:::

| ❌ 别这么说 | ✅ 换成这么说 |
|---|---|
| 「我用 DPO 做的这个任务」 | 「我借用了 DPO 的 pairwise 结构，但做的是**判别任务上的标签空间偏好**」 |

| 「就是三个 trick 叠加」 | 「三项分别对应三种失败模式：分不开、没信息、纠缠」 |
| 「我的方法在所有数据上都最好」 | 「在 🟡待填 数据集上优势最大，在 🟡待填 上提升较小，原因是……」 |

## 13. 自测（合上文档，60 秒内答完每一题）

:::qa 用一句话说清你的方法：把什么重构成了什么
把「标签分类」重构为「**标签空间上的相对偏好学习**」：不问"正确标签概率多少"，而问"正确标签相对竞争标签**好多少**"，并且这个优势是**以冻结参考模型为基线**的。
:::

:::qa 参考模型在方法里干了哪件事？一个词概括
**归一化**——把"这个实例本身有多难"从目标里除掉，让模型专注在参考模型也分不开的难样本上。
:::

:::qa 三项 loss 分别对应哪种失败模式
- 偏好 loss → 治**分不开**（边界不宽）
- 互信息 → 治**没信息靠捷径**（表示里丢标签语义）
- 监督对比 → 治**纠缠**（类内散、类间近）
:::

:::qa 面试官说"这不就是 DPO 吗"，你的三句话回答
1. 形式上借用了 log-sigmoid 的 pairwise 结构；
2. 但偏好对是"两个**标签**谁更对"，不是"两个回答谁更好"，而且是**从监督标签自动构造**的，不需要偏好标注；
3. 参考模型的角色也不同：DPO 用它约束 KL，我用它做**实例难度归一化**。
:::

:::qa 为什么用 Macro-F1 而不是 Accuracy
类别不均衡，Accuracy 会被多数类主导；Macro-F1 对每类等权，能反映小类（通常是难类）的真实表现，对"边界是否稳"更敏感。
:::

:::qa 你这个方法最大的局限（30 秒版）
三条：依赖标签空间已知；偏好对是启发式构造的、没按难度加权；三项权重换数据集要重搜。最后补一句"第二条是我最想改的"。
:::
