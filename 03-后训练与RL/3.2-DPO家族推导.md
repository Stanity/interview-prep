# 3.2 DPO 家族推导（能白板一步步推出来）

> **为什么这篇要能推导**：字节 Top20 高频里「GRPO vs PPO/DPO」是五星第一，而 DPO 推导是**区分度最高的一题** —— 大多数人只会说"DPO 不需要 reward model"，但说不出**为什么能消掉**。
> **本文目标**：让你能在白板上从 RLHF 目标一步步推到 DPO loss，并解释每一步为什么成立。
> **标注**：`★★★` 必背 ｜ 推导部分建议**亲手抄三遍**（只读不写记不住）

---

## 1. 一句话定位

:::card 30 秒版
「DPO 不是"另一种 RLHF"，而是**把 RLHF 的目标解析求解之后再做训练**。

具体说：RLHF 的目标是 `max E[r] − β·KL`，这个目标对每个 prompt 有**闭式最优解** `π* ∝ π_ref·exp(r/β)`。从这个式子反解出奖励 `r = β log(π*/π_ref) + β log Z(x)`，代进 Bradley-Terry 偏好模型后，那个 **`Z(x)` 正好相消** —— 于是 loss 里只剩下 `log(π_θ/π_ref)`，**奖励模型和采样都不需要了**。

所以 DPO 的本质是：**用策略自身的 log-ratio 当作隐式奖励**。」
:::

---

## 2. 七步推导（核心，必须能白板复现）

### 记号先立清楚

| 记号 | 含义 |
|---|---|
| `x` | prompt（输入） |
| `y` | response（输出序列） |
| `π_θ(y\|x)` | 待训练策略 |
| `π_ref(y\|x)` | 参考策略（通常是 SFT 模型，**冻结**） |
| `r(x,y)` | 奖励 |
| `(x, y_w, y_l)` | 偏好三元组：`y_w` = chosen（更好），`y_l` = rejected |

---

### Step 1｜RLHF 的目标函数

```
max_θ  E_{x~D} [ E_{y~π_θ(·|x)} r(x,y) ]  −  β · D_KL[ π_θ(·|x) ‖ π_ref(·|x) ]        (1)
```

把 KL 展开：
```
D_KL = E_{y~π_θ} [ log (π_θ(y|x) / π_ref(y|x)) ]
```

于是 (1) 等价于：
```
max_θ  E_{x~D, y~π_θ} [ r(x,y) − β · log (π_θ(y|x)/π_ref(y|x)) ]                       (2)
```

:::card 这一步的物理解释（面试要能说）
- 第一项：**追求高奖励**
- 第二项：**别离 π_ref 太远**（β 越大越保守）

**为什么要有第二项**：只有第一项时，策略会找到奖励模型的漏洞（reward hacking），输出偏激、重复、不像人话。KL 项把它拴在"人话分布"附近。
:::

---

### Step 2｜逐点求闭式最优解

对固定的 `x`，内层优化可以**对每个 y 独立**进行（约束只有一个：概率和为 1）：

```
max_π  Σ_y π(y|x) · [ r(x,y) − β · log (π(y|x)/π_ref(y|x)) ]
s.t.   Σ_y π(y|x) = 1
```

构造拉格朗日函数（`λ` 是约束的乘子）：
```
L = Σ_y π(y) [ r(x,y) − β log(π(y)/π_ref(y)) ]  −  λ ( Σ_y π(y) − 1 )
```

对某个具体的 `π(y)` 求偏导并令其为 0：
```
∂L/∂π(y) = r(x,y) − β [ log(π(y)/π_ref(y)) + 1 ] − λ = 0
```

整理：
```
β · log(π(y)/π_ref(y)) = r(x,y) − β − λ
π(y)/π_ref(y) = exp( (r(x,y) − β − λ) / β )
             = exp(r(x,y)/β) · exp(−1 − λ/β)
```

把 `exp(−1 − λ/β)` 这个**与 y 无关的常数**写成 `1/Z(x)`，得到闭式解：

```
π*(y|x) = (1/Z(x)) · π_ref(y|x) · exp( r(x,y)/β )                                       (3)
```

其中配分函数（归一化常数）：
```
Z(x) = Σ_y π_ref(y|x) · exp( r(x,y)/β )
```

:::card 这个式子的三个直觉
1. **π* 是以 π_ref 为先验、按 exp(r/β) 重新加权的分布** —— 像"在参考模型上做一次指数倾斜（exponential tilting）"
2. **β → ∞**：`exp(r/β) → 1`，π* → π_ref（**完全不学**）
3. **β → 0**：π* 集中到 `argmax_y r`（**只追奖励**，最激进）
:::

---

### Step 3｜反解出"隐式奖励"

对 (3) 取对数：
```
log π*(y|x) = log π_ref(y|x) + r(x,y)/β − log Z(x)
```

移项，把 `r` 表达成策略的函数：
```
r(x,y) = β · log( π*(y|x) / π_ref(y|x) )  +  β · log Z(x)                              (4)
```

:::card 这就是"隐式奖励"
**关键观察**：`Z(x)` **只依赖 x，不依赖 y**。
所以对同一个 `x` 的两个不同回答 `y_w`、`y_l` 做**差**时，`β log Z(x)` 这一项会**完全相消**。

> 这就是 DPO 能去掉奖励模型的**数学根源** —— 我们需要的从来不是 `r` 的绝对值，而是**两个回答的奖励差**，而差值可以用策略自身的 log-ratio 表示。
:::

---

### Step 4｜Bradley-Terry 偏好模型

人类偏好的标准建模（也是奖励模型训练时用的假设）：
```
P(y_w ≻ y_l | x) = σ( r(x,y_w) − r(x,y_l) )                                            (5)
```

把 (4) 代入差值：
```
r(x,y_w) − r(x,y_l)
  = [ β log(π*(y_w)/π_ref(y_w)) + β log Z(x) ] − [ β log(π*(y_l)/π_ref(y_l)) + β log Z(x) ]
  = β [ log(π*(y_w)/π_ref(y_w)) − log(π*(y_l)/π_ref(y_l)) ]                            (6)
```

**`β log Z(x)` 相消了。** 现在这个偏好概率**只由策略本身和参考策略决定**，不再需要 `r`。

---

### Step 5｜得到 DPO loss

用 `π_θ` 替换 `π*`（我们的目标就是让 `π_θ` 逼近最优策略），最大化偏好数据的对数似然，等价于最小化负对数似然：

```
L_DPO(θ) = − E_{(x,y_w,y_l)~D} [ log σ( β [ log(π_θ(y_w|x)/π_ref(y_w|x)) − log(π_θ(y_l|x)/π_ref(y_l|x)) ] ) ]
```
**(7)**

定义**隐式奖励** `r̂_θ(x,y) = β · log( π_θ(y|x)/π_ref(y|x) )`，则 (7) 可以写成非常干净的形式：

```
L_DPO = − E [ log σ( r̂_θ(x, y_w) − r̂_θ(x, y_l) ) ]
```

:::card 面试时可以这样口述这个 loss
「DPO 的 loss 就是：**用策略相对参考模型的 log-ratio 当作隐式奖励，然后要求 chosen 的隐式奖励高于 rejected**，用 log-sigmoid 做 pairwise 分类。」
:::

---

### Step 6｜梯度（这步能推导出来就很加分）

对 (7) 求梯度。设
`z = β [ log(π_θ(y_w)/π_ref(y_w)) − log(π_θ(y_l)/π_ref(y_l)) ]`，`L = −log σ(z)`。
因为 `d/dz [−log σ(z)] = −(1 − σ(z)) = −σ(−z)`：

```
∇_θ L_DPO = − β · E[ σ( r̂_θ(x,y_l) − r̂_θ(x,y_w) ) · ( ∇log π_θ(y_w|x) − ∇log π_θ(y_l|x) ) ]
```
**(8)**

:::card 梯度的三句读法（这段是面试的高光点）
1. **权重 `σ(r̂_l − r̂_w)`**：如果模型把 rejected 判得比 chosen 还高（**判错了**），这个 sigmoid 接近 1 → **梯度大**；判对时接近 0 → **梯度小**。
   → **DPO 自动聚焦在"当前判错的样本"上**，这是它自带的难例挖掘。
2. **方向**：`+∇log π_θ(y_w)` 提升 chosen 概率，`−∇log π_θ(y_l)` 压低 rejected 概率。
3. **参考模型的作用**：`r̂` 里含 `log π_ref`，所以提升/压低的幅度是**相对参考模型**的 —— 参考模型本来就很自信的地方，改动幅度会被抑制。
:::

---

### Step 7｜一张图记住整个推导

```
RLHF 目标  max E[r] − β·KL
      │  逐点求闭式解（拉格朗日）
      ▼
π* ∝ π_ref · exp(r/β)          ← 最优策略的"形状"
      │  取对数反解
      ▼
r = β log(π*/π_ref) + β log Z(x)   ← 隐式奖励（含 Z）
      │  代入 Bradley-Terry，两个 y 相减
      ▼
Z(x) 相消 ⟹ 只需要 r 的差值
      │  负对数似然
      ▼
L_DPO = −log σ( r̂(y_w) − r̂(y_l) ),  r̂ = β log(π_θ/π_ref)
```

## 3. 四个必须能讲的局限

:::card ① 长度偏置
`log π(y|x)` 是**逐 token logprob 之和**，都是负数 → **序列越长，和越负**。
DPO loss 里两侧都是这个量，理论上对称，但实际中：
- 当 chosen 明显长于 rejected 时，模型被训练成"更偏好长回答"
- 实测现象：DPO 训练后输出**变长**，且长度与奖励不完全相关

**对策**：长度归一化（用平均 logprob，如 SimPO）、长度惩罚、在评测里单独监控长度分布。
:::

:::card ② Likelihood Displacement（可能性位移）
DPO 只约束**差值**，不约束**绝对水平**。
所以可能出现：chosen 的 `log π_θ(y_w)` **也下降了**，只要 `rejected` 下降得更多，loss 就在降。

**后果**：模型"更会选"了，但**生成质量/流畅度反而退化**（因为 chosen 的绝对概率被压低了）。

**对策**：混入 SFT loss（如 ORPO 的做法）、加 chosen 的绝对约束、或用 IPO 的平方损失限制位移幅度。
:::

:::card ③ Off-policy 退化
DPO 是**离线**的：偏好数据由 `π_ref` 或别的模型生成，训练过程中**不再采样**。
随着 `π_θ` 偏离初始分布，训练数据越来越"过时" → 收益递减。

**对策**：迭代式 DPO（用当前模型采样新回答 → 用强模型/人工打分 → 构造新偏好对）、online/self-play DPO。
:::

:::card ④ 依赖 reference model，且不能探索
- 必须有 `π_ref`（通常=SFT 模型），且 **`π_ref` 的质量决定上限**：参考模型完全不会的方向，DPO 也学不出来
- **不能探索**：只能从已有偏好数据里学，无法发现数据外更好的回答（这正是 GRPO/RLVR 存在的理由）
:::

## 4. 家族：四种主流改进各改了什么

| 变体 | 一句话动机 | 关键改动 | 是否需要 ref |
|---|---|---|---|
| **DPO** | 基线 | `−log σ(β·(logratio_w − logratio_l))` | ✅ 需要 |
| **IPO** | DPO 在"确定性偏好"下会过拟合（σ 饱和到 1） | 把 log-sigmoid 换成**平方损失**，要求 log-ratio 差**恰好等于** `1/(2β)`（而不是越大越好） | ✅ 需要 |
| **KTO** | 现实里往往只有"这个回答好/坏"，**没有成对比较** | 只需要**二元标签**；借鉴前景理论做**不对称损失**（对坏样本的惩罚更重） | ✅ 需要（用 KL 估计做参考点） |
| **ORPO** | 想要**一步到位**（SFT + 对齐合起来），且省掉 reference | 把 **SFT loss** 与 **odds-ratio 惩罚**相加 | ❌ **不需要** |
| **SimPO** | 想更简单且**消除长度偏置** | 用**长度归一化的平均 logprob** + 目标 margin `γ` | ❌ **不需要** |

:::card 三个"不需要 reference"的动机说清
- **ORPO**：观察到 SFT 本身就有"压低 rejected"的作用（因为 SFT 只提 chosen），所以把 SFT loss 和偏好项合并，用 `odds = p/(1-p)` 的比值做惩罚，不再需要 `π_ref` 做锚点
- **SimPO**：直接假设最优策略就是当前策略（去掉 KL 项），改用**长度归一化 logprob** 当隐式奖励，并引入 margin `γ` 要求 chosen 至少高出 γ

**代价**：省掉 reference 的显存（约一半），但**失去了"防止偏离人话分布"的锚**，所以对小数据/大模型更敏感。
:::

:::card 各变体的"一句话适用场景"
- **DPO**：通用默认，有参考模型、有偏好对
- **IPO**：偏好数据**噪声大或确定性太强**（每条都有唯一正确答案）时更稳
- **KTO**：只有**单条反馈**（点赞/点踩、通过/不通过）时
- **ORPO**：**算力紧张 + 想一步到位**（SFT 与对齐合并）
- **SimPO**：**在意长度偏置**、或者想进一步省显存
:::

## 5. β 到底是什么（面试高频）

:::card 三个视角，说一个就够，说全更稳
**视角 1：温度**
从 `π* ∝ π_ref · exp(r/β)` 看，`β` 就是**奖励的温度**：
- `β` 大 → 奖励被"压平" → 最优策略接近 `π_ref`（保守）
- `β` 小 → 奖励被放大 → 最优策略集中到高奖励回答（激进）

**视角 2：KL 惩罚系数**
从目标 (2) 看，`β` 是"偏离 π_ref 的代价"。它直接决定 **Δ_KL 的预算**。

**视角 3：隐式奖励的尺度**
`r̂ = β log(π_θ/π_ref)`，所以 `β` 决定"log-ratio 换算成奖励时放大多少倍"。

**实践取值**：DPO 论文常用 **β = 0.1**；
- 太小（如 0.01）→ 过度偏离参考模型，训练容易崩、输出胡言乱语
- 太大（如 0.5+）→ 几乎不改变模型（学不到东西）
- **β 和 lr 是耦合的**：β 小通常要配小 lr
:::

## 6. 实现要点（被问"你写过 DPO 吗"时用）

:::card 工程细节清单
1. **logprob 只算 response 部分**：prompt 的 token 不计入 `log π(y|x)`
2. **四次前向**：`π_θ` 对 `y_w` / `y_l`，`π_ref` 对 `y_w` / `y_l`（`π_ref` 不用梯度，但要前向）→ 显存约等于 **2 个模型**
3. **数值稳定**：先 `log_softmax` 再 gather 目标 token 的 logprob，避免"先 softmax 再 log"
4. **长度归一化**（可选）：是否除以 `|y|` 会改变语义，DPO 原论文**不归一化**
5. **`π_ref` 可以量化/offload**：它只做前向，bf16 或 4bit 都行
6. **数据顺序**：偏好对里 chosen/rejected 的**位置**要随机化，避免位置偏置被学进去
:::

## 7. 【挂点】你的 RePref-Fact 和 DPO 是同一形式

:::card 这个对照非常值钱（能显示你真的理解了公式）
**DPO**：
```
L = − log σ( β ( log(π_θ(y_w)/π_ref(y_w)) − log(π_θ(y_l)/π_ref(y_l)) ) )
```
拆开就是：
```
= − log σ( β { [log π_θ(y_w) − log π_ref(y_w)] − [log π_θ(y_l) − log π_ref(y_l)] } )
```

**你的 RePref-Fact（公式 1、2）**：
```
δθ(x) = [ sθ(x,y⁺) − sθ(x,y⁻) ] − [ s_ref(x,y⁺) − s_ref(x,y⁻) ]
L_pref = − log σ( β · δθ(x) )
```

**把 δθ 重排**：
```
δθ(x) = { [sθ(x,y⁺) − s_ref(x,y⁺)] − [sθ(x,y⁻) − s_ref(x,y⁻)] }
```
:::

:::card 结论：两者**数学上完全同构**
只要做三个替换：
| DPO | 你的 RePref-Fact |
|---|---|
| `log π_θ(y\|x)` | `sθ(x,y)`（标签分数，不是序列 logprob） |
| `log π_ref(y\|x)` | `s_ref(x,y)`（参考模型的标签分数） |
| `y_w / y_l`（两个回答） | `y⁺ / y⁻`（同一实例的两个**标签**） |

**所以最硬的一句面试话术**：
> 「我的偏好 gap `δθ(x)` 本质上就是 **DPO 隐式奖励的差** `r̂(y⁺) − r̂(y⁻)` —— 我只是把它从**序列 logprob** 搬到了**标签分数**上，从"比较两个回答"变成"比较两个标签"。参考模型在我的设定里不是做 KL 约束，而是提供**实例难度基线**（因为相减后 `Z(x)` 同样相消，剩下的就是这个实例本身有多难）。」

**为什么这个回答强**：它同时证明了 ① 你懂 DPO 的推导 ② 你懂自己方法的数学本质 ③ 你的改造是有理由的（判别任务没有"序列 logprob"，但有"标签分数"）。
:::

## 8. 十个追问预答

:::qa 为什么 DPO 不需要 reward model？一句话
因为 RLHF 目标的最优策略有闭式解 `π* ∝ π_ref exp(r/β)`，反解出 `r = β log(π*/π_ref) + β log Z(x)`；代进 Bradley-Terry 后两个 y 相减，**只依赖 x 的 `Z(x)` 正好消掉** —— 于是只需要 `r` 的**差值**，而差值可以用策略自身的 log-ratio 表示。
:::

:::qa DPO 是 on-policy 还是 off-policy
**off-policy**（离线）。训练数据是固定的偏好对，训练过程中不再从 `π_θ` 采样。
后果：随着 `π_θ` 偏离，数据越来越"过时" → 迭代式 DPO / online DPO 就是为修这个问题。
:::

:::qa β 调大调小分别会怎样
β 大 → 最优策略更接近 π_ref（保守，可能学不到东西）；β 小 → 更激进追奖励（容易崩、输出跑飞）。常用 0.1。
本质是"奖励的温度"，也是 KL 惩罚系数。
:::

:::qa DPO 训练后模型变啰嗦，为什么
**长度偏置**：`log π` 是 token logprob 之和（负值累加），长序列天然更负。DPO 只约束差值，当 chosen 长于 rejected 时，模型学到"更长=更好"。
对策：长度归一化（SimPO）、长度惩罚、监控长度分布。
:::

:::qa 什么是 likelihood displacement
DPO 只约束"chosen 比 rejected 高多少"，**不约束 chosen 的绝对概率**。所以可能出现 chosen 的 logprob 也下降（只要 rejected 降得更多）→ 模型"更会选"但**生成质量退化**。
对策：混 SFT loss（ORPO）、IPO 的平方约束、监控 chosen 的绝对 logprob。
:::

:::qa IPO / KTO / ORPO / SimPO 各自解决什么问题
- **IPO**：DPO 在确定性偏好下 σ 饱和 → 过拟合；改成平方损失，要求 log-ratio 差**恰好**为 1/(2β)
- **KTO**：没有成对数据，只有单条好/坏 → 二元标签 + 前景理论的不对称损失
- **ORPO**：想一步到位且省掉 reference → SFT loss + odds-ratio 惩罚
- **SimPO**：想消除长度偏置 + 省 reference → 长度归一化平均 logprob + margin γ
:::

:::qa ORPO 和 SimPO 都不要 reference，那"防止跑飞"怎么办
靠两个替代机制：
- **ORPO**：SFT loss 本身就在"提 chosen"，加上 odds-ratio 惩罚（用 `p/(1-p)` 的比值），形成隐式约束
- **SimPO**：引入 **margin γ** 要求 chosen 的（长度归一化）分数至少高出 γ，避免无界优化

**代价**：失去了 π_ref 这个"人话锚点"，所以**小数据或强策略下更容易跑偏**。
:::

:::qa DPO 能不能用来提升模型的推理能力
有限。两个限制：
1. **不能探索**：偏好数据里没有的推理路径学不到
2. **没有"对错"信号**：人类偏好 ≠ 正确性（可能更偏好"看起来有条理但错了"的回答）
所以数学/代码这类任务，**RLVR/GRPO 比 DPO 更合适**（有可验证奖励 + 在线采样）。
:::

:::qa DPO 的显存比 PPO 省多少
- **PPO**：4 个模型，其中 2 个（actor、critic）要训练（权重+梯度+Adam 状态）
- **DPO**：2 个模型，只有 policy 要训练，reference 只做前向
7B 全参下：PPO ≈ 需要 8×80G 起步；DPO ≈ 2–4 张 80G 可行（取决于是否 LoRA）。
**本质**：DPO 省掉了 critic（同规模）和在线采样。
:::

:::qa 如果 π_ref 本身很差，DPO 会怎样
两个后果：
1. **上限受限**：`π* ∝ π_ref exp(r/β)`，π_ref 支持不到的方向，π* 也到不了（概率为 0 的地方加权还是 0）
2. **偏移被放大**：`r̂ = β log(π_θ/π_ref)`，π_ref 在某些 token 上概率极低时，log-ratio 会异常大 → 训练不稳

**对策**：先把 SFT 做扎实，再对齐。
:::

:::qa 【挂点】你的方法是 DPO 吗
「形式上同构 —— 我的 δθ(x) 就是 DPO 隐式奖励的差 `r̂(y⁺) − r̂(y⁻)`，只是把序列 logprob 换成了**标签分数**、把"两个回答"换成了"同一实例的两个标签"。
但三处不同：**偏好对从监督标签自动构造**（不需要偏好标注）、**参考模型做实例难度归一化而不是 KL 约束**、**额外加了两个表示层目标**。」
:::

## 9. 陷阱

| ❌ 别这么说 | ✅ 换成这么说 |
|---|---|
| 「DPO 是简化版 RLHF」 | 「DPO 是 RLHF 目标的**闭式解重参数化**，把 RM 消掉了」 |
| 「DPO 不需要参考模型」 | 「DPO **需要** reference（算 log-ratio），不需要的是 **reward model**；ORPO/SimPO 才不需要 reference」 |
| 「Z(x) 可以忽略」 | 「`Z(x)` 只依赖 x，**在相减时精确相消**，不是忽略」 |
| 「β 越大越保守 / 越小越好」 | 「β 是温度也是 KL 系数：大→接近 π_ref，小→激进；常用 0.1」 |
| 「DPO 比 PPO 好」 | 「DPO 便宜稳定但 off-policy 不能探索；PPO 在线但贵且难调」 |
| 「DPO 能提升推理」 | 「推理更依赖可验证奖励 + 在线采样，那是 RLVR/GRPO 的地盘」 |

## 10. 自测（8 题，能默写公式才算过）

:::qa 写出 RLHF 的目标函数，并解释两项各是什么
`max E_{y~π_θ}[r(x,y)] − β D_KL[π_θ‖π_ref]`。第一项追高奖励，第二项限制偏离参考模型（防 reward hacking）。
:::

:::qa 最优策略的闭式解是什么？β 取极限会怎样
`π*(y|x) = (1/Z(x)) π_ref(y|x) exp(r(x,y)/β)`，`Z(x)=Σ_y π_ref exp(r/β)`。
β→∞：π*→π_ref（不学）；β→0：集中到 argmax r（激进）。
:::

:::qa 隐式奖励怎么来的？为什么 Z(x) 能消掉
对上式取对数移项得 `r = β log(π*/π_ref) + β log Z(x)`。`Z(x)` 只依赖 x，不依赖 y，所以在算 `r(y_w) − r(y_l)` 时相消。
:::

:::qa 默写 DPO loss
`L = −E[log σ(β( log(π_θ(y_w|x)/π_ref(y_w|x)) − log(π_θ(y_l|x)/π_ref(y_l|x)) ))]`
（或写成 `−log σ(r̂(y_w) − r̂(y_l))`，`r̂ = β log(π_θ/π_ref)`）
:::

:::qa DPO 的梯度说明了什么？一句话
权重 `σ(r̂_l − r̂_w)`：判错时梯度大、判对时梯度小 → **自带难例挖掘**；方向是提 chosen、压 rejected。
:::

:::qa DPO 训练后输出变长，机制是什么
`log π` 是 token logprob 之和（负值累加），长序列更负；DPO 只约束差值，于是模型学到"更长=更好"。
:::

:::qa 举两个"不需要 reference model"的变体，它们各自怎么做到
- **ORPO**：SFT loss + odds-ratio 惩罚（`odds = p/(1-p)` 的比值）
- **SimPO**：长度归一化的平均 logprob + 目标 margin γ
:::

:::qa 你的 RePref-Fact 偏好 gap 和 DPO 什么关系
数学同构：`δθ(x) = r̂(y⁺) − r̂(y⁻)`，只是把序列 logprob 换成标签分数、把两个回答换成两个标签；参考模型从"KL 锚点"变成"实例难度基线"。
:::
