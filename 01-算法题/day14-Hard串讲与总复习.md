## 三、复杂度速查表（面试官一定会问一句）

| 结构 / 操作 | 平均 | 最坏 |
|---|---|---|
| `unordered_map` 查找 | O(1) | O(n)（哈希碰撞，可被构造攻击） |
| `map` / `set`（红黑树） | O(log n) | O(log n) |
| 堆 push/pop | O(log n) | O(log n) |
| 并查集（路径压缩 + 按秩合并） | O(α(n)) ≈ O(1) | O(α(n)) |
| 快速选择 | O(n) | O(n²)（pivot 最差） |
| 排序 | O(n log n) | O(n log n)（`sort` 是内省排序） |
| Trie 插入/查询 | O(L) | O(L) |
| 单调栈整体 | O(n) | O(n) |

**面试话术**：先说时间，再说空间，最后说一句"能不能优化"（例如"这里可以滚动数组把空间降到 O(1)"）。

## 四、卡住时的三句话（比"我不会"值钱得多）

1. **"我先说暴力解法"**：把最直接的 O(n²) / 回溯写出来 —— 先拿住基本分。
2. **"卡在这里是因为我需要 O(1) 查询某个历史值，所以我想用哈希/单调栈"**：把"卡点"翻译成"需要什么数据结构"。
3. **"我先写主体，边界我再补"**：把空输入、单元素、重复元素、溢出四类边界留到最后统一处理。

**绝对不要**：沉默超过 30 秒、直接要答案、写一大段自己讲不清的代码。

## 六、终极自测（4 题，答不出就回去重刷对应篇）

:::qa 手写 LRU 时，为什么节点里必须存 key？少了会怎样
因为逐出时要 `mp.erase(key)`，而 `map` 的键是 key（不是节点指针）。如果节点里只有 val，被逐出时你拿到的是节点指针，却**无法反查出对应的 key**，`map` 就删不掉 → 缓存里留下悬空条目。

一句话：**`map` 是 key→节点，所以节点必须能反推出 key**。
:::

:::qa 二分最难的不是写，而是选模板。你平时怎么决定用哪个
看问题问什么：
- 问"**第一个满足条件的位置**"（lower_bound / 插入位置 / 首末位置 / 中位数切分）→ 左闭右开 `[l, r)`，返回 `l`，答案可能是 `n`
- 问"**是否存在某个确定元素**"（查 target / 旋转数组）→ 闭区间 `[l, r]`，`while (l <= r)`

**不要在一个函数里混用两种**，这是二分写挂的头号原因。
:::

:::qa 单调栈为什么能把 O(n²) 降到 O(n)？栈里存下标还是存值
因为每个元素**最多入栈一次、出栈一次**，总操作数 2n。
存**下标**：既能比较大小（`a[st.top()]`），又能算距离/宽度（`i - st.top()`）。存值就丢了位置信息，算不了跨度。
:::

:::qa 面试官问"这个方案还有什么可以优化的"，你按什么顺序想
1. **时间**：能否用哈希/单调栈/二分把一层循环消掉？能否用堆把 O(n log n) 降到 O(n log k)？
2. **空间**：能否原地（滚动数组、双指针、原地标记）？
3. **常数**：能否用位运算（`bitset`、状态压缩）？
4. **工程**：数据量、并发、内存上限 —— 如果这是生产代码还要考虑什么？

答的时候**按顺序说**，即使优化不了也体现了系统性。
:::

## 八、错题本的正确用法（最后提醒一次）

每次卡壳，记录三样东西：

1. **卡在哪一步**：思路 / 边界 / 语法 / 复杂度
2. **正确做法一句话**（不是抄代码）
3. **下次见到同类题，我的第一反应应该是什么**

第 3 条最重要 —— 前两条只是复习，第 3 条才是**把题变成能力**。
