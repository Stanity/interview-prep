:::qa LC 49 · 字母异位词分组（Medium｜必刷）

**题目**
给你一个字符串数组 `strs`，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。
> 字母异位词：由重新排列源单词的所有字母得到的新单词（字母组成完全相同，顺序不同）。

**示例 1**
```
输入：strs = ["eat","tea","tan","ate","nat","bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2**
```
输入：strs = [""]
输出：[[""]]
```

**示例 3**
```
输入：strs = ["a"]
输出：[["a"]]
```

**约束**
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写英文字母

**提示 1（方向）**
异位词之间一定存在某个"共同特征"，把特征当 key 就能分组。什么变换会让 `eat / tea / ate` 变成同一个东西？

**提示 2（关键不变量）**
两个串是异位词 ⟺ **排序后相同** ⟺ **每种字母计数相同**。
用排序串当 key：O(L log L)；用 26 位计数当 key：O(L)。两者都是"规范形式（canonical form）"思路。

**提示 3（伪代码）**
```
mp: key -> list
for s in strs:
    key = sorted(s)
    mp[key].push(s)
return mp 的所有 value
```

**完整代码**

```cpp
// LC 49 字母异位词分组
// 规范形式做 key：排序后的字符串（同组必然相同）
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
using namespace std;

vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> mp;
    for (auto& s : strs) {
        string key = s;
        sort(key.begin(), key.end());     // 排序化规范形式
        mp[key].push_back(s);
    }
    vector<vector<string>> res;
    res.reserve(mp.size());
    for (auto& kv : mp) res.push_back(move(kv.second));
    return res;
}
```

**复杂度**：时间 O(n · L log L)（n 个串、长度 L），空间 O(n · L)。

**易错点**
- 用 `hash<string>` 或字符串长度当 key → 碰撞/漏分。
- 空串也要能分组：排序后仍是空串，逻辑天然覆盖，别特判掉。
- 对 `strs` 原地排序后再分组，会丢掉原始串（本题只要求分组，但别养成习惯）。

**面试追问**
- 字符集很大时怎么优化？→ 计数法：把 26/字符集计数数组序列化成 key，O(n·L)。
- 要求组内保持输入顺序？→ `push_back` 已经保序；若要求组间顺序，改用 vector 记录首次出现顺序。

:::qa LC 128 · 最长连续序列（Medium｜必刷）

**题目**
给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（**不要求序列元素在原数组中连续**）的长度。
请你设计并实现**时间复杂度为 O(n)** 的算法解决此问题。

**示例 1**
```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1,2,3,4]，长度 4
```

**示例 2**
```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
解释：最长序列 [0,1,2,3,4,5,6,7,8]，注意 0 重复出现，长度仍为 9
```

**示例 3**
```
输入：nums = []
输出：0
```

**约束**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

**提示 1（方向）**
要求 O(n) 就不能排序。用哈希集合支持 O(1) 的"某个数在不在"。但**不能对每个数都向上数**（那是 O(n²)）。

**提示 2（关键不变量）**
`x` 是某段连续序列的**起点** ⟺ `x-1` 不在集合里。只从起点开始向上数，则每个元素最多被访问两次（一次判起点、一次被数到），总复杂度 O(n)。

**提示 3（伪代码）**
```
st = set(nums)
for x in st:
    if x-1 in st: continue      // 不是起点
    y = x; while y+1 in st: y++
    best = max(best, y-x+1)
```

**完整代码**

```cpp
// LC 128 最长连续序列
// 哈希集合 + 只从序列起点向上数，保证 O(n)
#include <vector>
#include <unordered_set>
#include <algorithm>
using namespace std;

int longestConsecutive(vector<int>& nums) {
    unordered_set<int> st(nums.begin(), nums.end());   // 顺便去重
    int best = 0;
    for (int x : st) {
        if (st.count(x - 1)) continue;                 // 不是起点，跳过
        int y = x;
        while (st.count(y + 1)) y++;                   // 从起点一直数上去
        best = max(best, y - x + 1);
    }
    return best;
}
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**
- 忘记判起点 → 退化成 O(n²)（重复元素多时明显）。
- 遍历 `nums` 而不是 `st` → 重复值会被反复处理（不影响正确性但更慢）。
- 用 `x+1` 而不是 `x-1` 判起点 → 变成从终点数。

**面试追问**
- 要返回**序列本身**？→ 记录起点与长度，最后还原。
- 数据流式插入 + 随时查询最长连续段？→ 用并查集/哈希存"段长"，插入时合并左右段，O(1) 摊还。
:::

:::qa LC 560 · 和为 K 的子数组（Medium｜必刷）

**题目**
给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中**和为 `k` 的连续子数组**的个数。

**示例 1**
```
输入：nums = [1,1,1], k = 2
输出：2
解释：[1,1] 出现两次（下标 [0,1] 与 [1,2]）
```

**示例 2**
```
输入：nums = [1,2,3], k = 3
输出：2
解释：子数组 [1,2] 与 [3]
```

**示例 3**
```
输入：nums = [1,-1,0], k = 0
输出：3
解释：[1,-1], [0], [1,-1,0]
```

**约束**
- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

**提示 1（方向）**
连续子数组的和 = 两个前缀和之差。数"有多少个区间的和为 k" → 变形成：对每个前缀和 `sum`，数历史上有多少个前缀和等于 `sum - k`。

**提示 2（关键不变量）**
`pre[r] - pre[l-1] = k` ⟺ `pre[l-1] = pre[r] - k`。边扫边把前缀和出现次数存进哈希，就能 O(1) 查到匹配数。
**注意：nums 含负数，窗口和不再单调，所以不能用滑动窗口。**
必须初始化 `cnt[0] = 1`（空前缀），否则"从下标 0 开始"的区间全部漏掉。

**提示 3（伪代码）**
```
cnt = {0: 1}; sum = 0; res = 0
for x in nums:
    sum += x
    res += cnt.get(sum - k, 0)
    cnt[sum] += 1
```

**完整代码**

```cpp
// LC 560 和为 K 的子数组
// 前缀和 + 历史计数：res += count(sum - k)
#include <vector>
#include <unordered_map>
using namespace std;

int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> cnt;
    cnt[0] = 1;                       // 空前缀：让"从下标 0 开始"的区间也能被计入
    int sum = 0, res = 0;
    for (int x : nums) {
        sum += x;
        auto it = cnt.find(sum - k);
        if (it != cnt.end()) res += it->second;   // 先查历史，再把自己放进去
        cnt[sum]++;
    }
    return res;
}
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**
- 忘记 `cnt[0] = 1` → 少算所有从头开始的区间。
- 先 `cnt[sum]++` 再查 → 当 `k == 0` 时会把"空区间"算进去。
- 试图套滑动窗口 → 有负数时答案错误（最典型的踩坑）。

**面试追问**
- 若数组**全非负**，滑窗怎么写？→ 右扩累加，`> k` 时缩左，相等时计数并继续缩（注意 k=0 的边界）。
- 要返回**所有**这样的区间？→ 哈希里存"前缀和 → 下标列表"，回溯组合。
:::

:::qa LC 238 · 除自身以外数组的乘积（Medium｜必刷）

**题目**
给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中**除 `nums[i]` 之外其余各元素的乘积**。
- 题目数据保证数组之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位整数范围内。
- **请不要使用除法**，且在 O(n) 时间复杂度内完成。

**示例 1**
```
输入：nums = [1,2,3,4]
输出：[24,12,8,6]
解释：answer[0]=2*3*4=24, answer[1]=1*3*4=12, answer[2]=1*2*4=8, answer[3]=1*2*3=6
```

**示例 2**
```
输入：nums = [-1,1,0,-3,3]
输出：[0,0,9,0,0]
```

**约束**
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- 保证结果在 32 位整数范围内

**提示 1（方向）**
`answer[i] = (左边所有元素之积) × (右边所有元素之积)`。两次扫描即可：先从左往右把**前缀积**写进 `answer`，再从右往左乘上**滚动后缀积**。

**提示 2（关键不变量）**
第一次扫描后 `answer[i] = nums[0..i-1] 的积`；第二次扫描维护 `suf = nums[i+1..n-1] 的积`，把 `answer[i] *= suf` 后再把 `nums[i]` 并入 `suf`。**顺序不能反**。

**提示 3（伪代码）**
```
res[0]=1
for i in 1..n-1: res[i] = res[i-1]*nums[i-1]
suf = 1
for i in n-1..0:
    res[i] *= suf
    suf *= nums[i]
```

**完整代码**

```cpp
// LC 238 除自身以外数组的乘积
// 前缀积写进答案数组，再滚动后缀积乘回去：额外空间 O(1)
#include <vector>
using namespace std;

vector<int> productExceptSelf(vector<int>& nums) {
    int n = nums.size();
    vector<int> res(n, 1);

    for (int i = 1; i < n; i++)
        res[i] = res[i - 1] * nums[i - 1];    // 左侧乘积

    int suf = 1;
    for (int i = n - 1; i >= 0; i--) {
        res[i] *= suf;                        // 乘上右侧乘积
        suf *= nums[i];                       // 再把当前元素并入右侧
    }
    return res;
}
```

**复杂度**：时间 O(n)，空间 O(1)（除返回数组）。

**易错点**
- 用除法（有 0 会崩，且题目明令禁止）。
- 第二次循环里 `res[i] *= suf` 与 `suf *= nums[i]` 顺序颠倒。
- 忘记 `res[0]` 的初值是 1（左侧为空视为 1）。

**面试追问**
- 若允许除法，怎么处理 0？→ 统计 0 的个数：0 个用总积除，1 个只有该位置非 0，≥2 个全 0。
- 如果要求处理溢出（超出 32 位）？→ 换 `long long` 或取模。
:::

:::qa LC 41 · 缺失的第一个正数（Hard｜必刷）

**题目**
给你一个未排序的整数数组 `nums`，请你找出其中没有出现的**最小正整数**。
请你实现**时间复杂度 O(n)** 并且只使用**常数级别额外空间**的解决方案。

**示例 1**
```
输入：nums = [1,2,0]
输出：3
```

**示例 2**
```
输入：nums = [3,4,-1,1]
输出：2
```

**示例 3**
```
输入：nums = [7,8,9,11,12]
输出：1
```

**约束**
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

**提示 1（方向）**
长度 `n` 的数组最多装下 `1..n` 这 n 个正整数，所以**答案一定在 `[1, n+1]`**。既然如此，可以把"值 `x in [1,n]`"直接**放回下标 `x-1`** 的位置（原地哈希），再扫一遍找第一个 `nums[i] != i+1`。

**提示 2（关键不变量）**
交换必须同时满足三个条件：`x` 在 `[1,n]`、目标位置的值不相等（**避免重复值死循环**）、并且用 `while` 而不是 `if`（换过来的新值也得继续归位）。

**提示 3（伪代码）**
```
for i in 0..n-1:
    while nums[i] in [1,n] and nums[nums[i]-1] != nums[i]:
        swap(nums[i], nums[nums[i]-1])
for i in 0..n-1:
    if nums[i] != i+1: return i+1
return n+1
```

**完整代码**

```cpp
// LC 41 缺失的第一个正数
// 原地哈希：把值 x in [1,n] 放到下标 x-1，再找第一个错位的位置
#include <vector>
#include <algorithm>
using namespace std;

int firstMissingPositive(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n; i++) {
        // 三个条件缺一不可：范围、目标位置不相等（防死循环）、循环归位
        while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i])
            swap(nums[i], nums[nums[i] - 1]);
    }
    for (int i = 0; i < n; i++)
        if (nums[i] != i + 1) return i + 1;
    return n + 1;      // 1..n 都齐了，答案是 n+1
}
```

**复杂度**：时间 O(n)（每个元素最多被换到正确位置一次），空间 O(1)。

**易错点**
- 漏 `nums[nums[i]-1] != nums[i]` → 遇到重复值（如 `[1,1]`）死循环。
- 用 `if` 代替 `while` → 换过来的值没继续归位。
- 忘记判 `nums[i] <= n` → 下标越界。

**面试追问**
- 为什么答案上界是 `n+1`？→ 抽屉原理：n 个位置只能容纳 n 个值。
- 不允许修改输入怎么做？→ 用 `O(n)` 额外空间的 set，或用两次取负标记法（仍需读输入）。
- 如果数组里有 0 和负数？→ 它们永远不等于 `i+1`，自然被跳过。
:::

:::qa LC 189 · 轮转数组（Medium｜必刷）

**题目**
给定一个整数数组 `nums`，将数组中的元素向**右**轮转 `k` 个位置，其中 `k` 是非负数。
要求**原地**修改（尽量用 O(1) 额外空间）。

**示例 1**
```
输入：nums = [1,2,3,4,5,6,7], k = 3
输出：[5,6,7,1,2,3,4]
解释：向右轮转 1 步 → [7,1,2,3,4,5,6]；2 步 → [6,7,1,2,3,4,5]；3 步 → [5,6,7,1,2,3,4]
```

**示例 2**
```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
```

**约束**
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

**提示 1（方向）**
原地 + O(1) 空间的经典技巧：**三次反转**。整体反转 → 反转前 k 个 → 反转后 n-k 个。

**提示 2（关键不变量）**
整体反转把"后 k 个"搬到了前面，但顺序被倒置；随后分别把这两段各自反转回来，就得到了正确顺序。
另外 `k` 必须先对 `n` 取模（`k` 可能大于 `n`）。

**提示 3（伪代码）**
```
k %= n
reverse(0, n-1)
reverse(0, k-1)
reverse(k, n-1)
```

**完整代码**

```cpp
// LC 189 轮转数组
// 三次反转：整体 → 前 k → 后 n-k
#include <vector>
#include <algorithm>
using namespace std;

void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;                                          // k 可能大于 n
    reverse(nums.begin(), nums.end());               // ① 整体反转
    reverse(nums.begin(), nums.begin() + k);         // ② 反转前 k 个
    reverse(nums.begin() + k, nums.end());           // ③ 反转后 n-k 个
}
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**
- 忘记 `k %= n` → `k > n` 时越界崩溃。
- 三个 `reverse` 的边界写成 `begin()+k-1` / `end()-1` 之类，反而容易错（`reverse` 是左闭右开）。
- 用额外数组虽然简单，但会被追问"能不能 O(1) 空间"。

**面试追问**
- 另一种 O(1) 空间解法？→ 环状替换：`i → (i+k) % n` 循环，共 `gcd(n,k)` 轮，每轮走 `n/gcd` 步。
- 若要求左轮转？→ 等价于右轮转 `n-k` 步。
:::

## 今日复盘三问

1. 哈希题的两大模式分别是什么？（**查配对**：`need = target - x`；**查历史**：前缀和计数 `sum - k`）
2. 为什么 `560` 不能用滑动窗口，而"和 ≥ 某个值"的题就可以？（**负数破坏单调性**）
3. 原地算法题（41、189）的共同套路是什么？（**利用下标本身携带信息**：把值放到它"应该在"的位置上）
